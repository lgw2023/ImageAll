# ADR-085：时光故事限定素材试用与密集事件选片

- 状态：Accepted
- 日期：2026-09-20
- 范围：ImageAll 第五阶段本地试用；关联 ADR-081、082、083、084

## 试用隔离

用户本轮指定一个已接受的主体标签及其现有文件夹来源，允许只读使用原始照片。
正式目录库只用于按该标签读取元数据；本地私有脚本复制匹配的当前静态图片记录、
所需标签/来源 bookmark、时间、地点、收藏和文件指纹到隔离目录库。它不复制整库、
待审/已拒绝候选、Photos 来源或照片像素。隔离根通过系统目录选择器再次授权。

Debug 安装版的 `IMAGEALL_TIME_STORY_TRIAL_ROOT` 入口只启动故事工作台和已有文件夹
预览读取链路，不启动正式图库工作区、后台来源同步或 Photos 连接。故事项目、缩略图、
渲染包和任务根都留在授权的隔离目录；来源照片、正式标签和正式目录库不回写。
缩略图缓存沿用安全目录布局 `Caches/ImageAll/DerivedImages/v1`；隔离目录授权覆盖其父目录。
该入口仅用于本轮本机验证，不改变 Release 的日常启动路径，也不是通用导入平台。
隔离目录库的完整制作脚本和私有统计保存在第五阶段本地联合报告目录中。

## 选片与时长

真实草稿揭示：缺少兼容相似结果时，收藏加权让同一 24 小时内的照片占据大部分名额。
`time-place-balanced-v3` 在既有时期和连续地点首张保障之后，对自动补位最多选入
两个相距不足 24 小时的镜头；有足够不同拍摄窗口时，每个已覆盖的时间阶段至少尝试
三张代表。其余名额优先覆盖距离已选镜头更远的拍摄日期，距离按整天比较，同等距离再按
收藏、地点和分辨率择优；这避免某个收藏密集阶段在跨日后继续占满名额，并不硬分配
各年份比例。用户锁定或手改的镜头保留，连续地点首张仍有优先权；没有足够可区分素材时
允许少于 18 张。24 小时是相对时间窗口，不将无时区素材解释为 UTC 日历日期，
也不把时间邻近直接断言为相似照片。

工作台统一用规范化 30 fps 帧时间线显示带小数的预计成片时长，并始终注明约 60 秒
是目标。实际成片仍须以执行器结果、帧数和媒体检查确认；锁定镜头不会为凑整分钟而缩短。

## 验证与限制

合成回归覆盖密集收藏事件、早中期代表、原有地点回访及编辑保留。真实试用的身份、
画面完整度和叙事质量必须由用户审片；单靠标签、元数据或 ffprobe 不能判定。
