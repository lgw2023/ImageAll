# ADR-066：Mac 原生图库复制媒体绝对路径

- 状态：Accepted
- 日期：2026-09-02
- 范围：Mac 原生图库网格、图库瘦身结果网格

## 背景

用户需要在图库主界面或图库瘦身界面选中一张或多张媒体后，通过右键菜单复制原文件绝对路径。
ImageAll 的文件夹资产只持久化安全书签根与相对路径；Apple Photos 资产使用公开 PhotoKit 标识，
不存在产品可依赖的稳定原文件绝对路径。

## 决策

1. 两个网格统一提供右键操作：单项显示“复制该图片绝对路径”，多选显示
   “复制所选图片绝对路径（N）”；视频使用对应“视频”文案。
2. 若右键命中的项目已经位于当前选择中，复制整组选中项目；否则只复制右键命中的项目。
   主图库按当前网格顺序输出，图库瘦身按当前簇成员顺序输出。
3. 文件夹资产通过既有只读安全书签授权根解析，且只有通过 `RelativePathRules` 的当前 `file`
   locator 才能拼接绝对路径。解析不读取媒体内容，也不修改、移动或删除原文件。
4. 多条路径以一行一条的纯文本写入系统剪贴板。
5. Apple Photos 不探测或暴露 `.photoslibrary` 包内部路径，也不把临时 PhotoKit 导出 URL
   伪装成原文件路径。混合选择时复制可解析的文件夹路径并明确报告未解析数量；全部不可解析时不改写
   剪贴板，并提示 PhotoKit/来源授权边界。
6. 该能力只存在于 Mac 原生界面；Remote/Web 协议继续禁止返回本机绝对路径。

## 验证

- 模型测试覆盖主图库与图库瘦身的多选顺序、剪贴板写入及部分成功提示。
- 基础设施测试用合成临时目录、测试书签和测试数据库证明文件夹路径解析，并证明 Photos locator
  被排除。
- 自动化测试不得读取或遍历 `docs/LOCAL-TEST-DATA-SAFETY.md` 指定的受保护真实照片路径。
