# ADR-091 — App 随附 OpenMontage 与本地启动

状态：已实施，2026-09-22。

用户要求将源码与启动接入 App。原实现只交换任务文件，要求用户另开终端，且任务目录不一致会误报未连接。

决定：固定并随仓库保存 OpenMontage 源码快照（版本与摘要见 Vendor/OpenMontage/README.md）；构建时随 App 嵌入独立的 Launch Services helper 及 Python、Node、FFmpeg、Remotion、Chromium、字体运行依赖。ImageAll 保持现有沙盒与图库权限。helper 不继承图库沙盒，通过带随机标识的本地启动请求和 Launch Services URL 消息操作导出的任务包，不接收脚本、命令或原图库凭据。

用户在创作面板或模板库点击“启动本地制作”，首次安装版本化运行目录，启动幂等执行器，再验证实时心跳；界面显示启动中、成功、错误或超时。已有目录授权继续使用；无配置时使用 App Application Support 下的默认任务目录。依赖不在用户点击时下载。

运行目录是可写副本，以支持 Remotion 缓存。源码和依赖版本摘要绑定；旧运行版本不自动删除，已有任务不取消。App 退出不停止已提交制作。旧外部执行器若已就绪则复用，不强杀或替换进行中的制作。

范围：接入既有执行协议及模板渲染；自由创作仍沿用既有 Agent 生成方案流程，启动执行器不等于自动新增 AI 服务。无真实照片读写授权扩大。源码 AGPL 及随附依赖许可证保留；发行前另做完整发行审计，本轮为本机日常 App。

验收：构建签名；不依赖外部 OpenMontage checkout 的合成任务启动、重复启动、模板视频制作；日常 App 可见启动入口和状态。自动化只用合成素材。


## 验收结果

- Debug 构建与嵌套代码签名校验通过；日常 App 已备份后更新。
- 默认目录创建、可访问性以及已有无效 bookmark 不静默回退：1 个聚焦 XCTest 通过。
- 随附运行副本在仅包含 bundled bin 与系统路径的 PATH 下完成两种模板：文字卡 165 帧、照片字幕 135 帧；均 1080×1920、30 fps，全帧校验通过。
- 日常 App 的合成验收模式中，实际点击启动按钮，显示“本地制作已启动并连接”；点击开始本地制作，生成 1920×1080、30 fps、105 帧成片，App 显示“制作完成”和已验证成片。
- 重复点击启动复用相同执行器 PID。合成验收无真实素材访问。
- 初版命令行参数启动没有完成 App 沙盒到 helper 的消息交付，已改为系统 URL 消息；先打开 helper 刷新注册，再发送请求。仅 URL 不能启动，必须匹配 App 在所选目录写入的一次性 token。

当前实现针对本机 arm64 构建。退出 App 后已启动的执行器可继续完成任务；未加入开机自启动或服务自动升级，不强制结束旧执行器任务。
