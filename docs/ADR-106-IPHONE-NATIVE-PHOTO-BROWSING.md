# ADR-106：iPhone 照片浏览与选片的原生界面

- 状态：Accepted（2026-10-09，用户要求先在 Simulator 向 iOS 照片设计语言靠拢）
- 范围：此 iPhone 浏览、已选内容、待分享摘要；承接 [ADR-105](ADR-105-IPHONE-SHARE-WORKSPACE.md)

## 选择与取舍

照片成为浏览页的主体：系统大标题、边到边的紧凑正方形网格、照片／视频角标、收藏角标。标签和 ImageAll 集合的创建与改名保留在独立“整理”页，不挡在照片前面；现有批量加入已授权范围仍明确先预览数量、再确认，不把“全部已授权”暗示为任意选片器。

本决策将 ADR-105 的选片列表布局替换为懒加载网格，状态与操作契约沿用 ADR-105。已选内容默认点击预览，进入“选择”模式后点击勾选；选择模式支持全选和批量移出。移出操作采用明确文字，不使用容易误解为删除照片的垃圾桶图标。任务执行期间只能预览，不能进入选择模式。预览仍是派生照片或视频封面，不新增视频播放、编辑、源端删除或下载。

待分享使用少量真实所选缩略图和数量摘要，不在首页构建数千项。目标和任务状态仍在首屏；固定主操作保留。更多操作和高级迁移统一进入系统工具栏菜单，任务期间禁用；错误原因仍显示在任务区域。相簿目录默认开启及用户保存的关闭值沿用 ADR-105。

采用系统字体、语义颜色、NavigationStack、工具栏、菜单、Sheet 和按钮样式。iOS 26 使用系统提供的玻璃按钮；旧版本用标准样式回退。内容区域不叠加装饰性玻璃。依据 [Apple 原生新设计指引](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass)，让系统管理导航外观，保持内容可读与辅助功能适配。视觉接近照片的浏览与选择习惯，仍保留 ImageAll 的待分享、整理信息与 Mac 入库语义。

## 保留与验证

不修改传输实现、配对、业务数据契约、原件与整理信息同批发送、旧批次或续传记录。当前用户表示无有线手机连接，只做 Simulator 验收，不自动恢复真实传输。

共享的网格、缩略图、选择页和 Dashboard 用显式 Debug 合成入口验收。合成缩略图由代码绘制，identifier 为 nil，先于 PhotoKit 分支返回；不创建生产模型、资料库或连接。实际缩略图请求禁止网络，离开时取消请求。验证大批量、预览／选择／移出、运行时只读、失败下一步、深色与大字体，并构建当前 Xcode 项目。真实设备页面及整批传输稳定性仍为未验收。

## 2026-10-10 真机预览补充

重新连接真机后，观察到部分已选项目的预览只有占位图，没有解释。预览需明确区分载入中与当前无法预览；PhotoKit 无法取得资产或本机预览时，保留选片记录并提示到系统照片核对，不据此移出范围，也不开启网络下载。已有低清预览不应被后续空回调清掉；PhotoKit 的异步图像请求可能多次回调，依据 [Apple PhotoKit 回调说明](https://developer.apple.com/documentation/photos/phimagemanager/requestimage(for:targetsize:contentmode:options:resulthandler:)) 处理临时图像与最终结果。黑色预览 Sheet 使用局部深色外观，保证导航标题和说明可读，不改变其他页面或系统外观。

该补充只改派生缩略图与预览展示；不读取原件、不改传输、配对或整理信息契约。Simulator 验证无标识的合成不可用预览，真机验证实际不可用项目与可用项目的预览和退出。详细验收证据保存在本轮构建目录。

本日追加验收：当前项目的 Simulator／设备构建和六组状态检查通过，最终版本已更新至 iPhone 16 Pro Max（iOS 26.6.2）。真机观察到 2,889 项选择（2,498 张照片、391 个视频）、原有 Mac 目标和开启的相簿目录选项；已选内容、可用／不可用预览、关闭后原有外观、更多操作和高级页面均完成只读检查。前文真机未验收状态为 2026-10-09 记录，本日补齐上述 UI 验收；整批传输、接收／入库和迁移稳定性仍未验收，未启动真实传输。
