# ADR-084：时光故事素材就绪与可解释编辑

- 状态：Accepted
- 日期：2026-09-20
- 范围：原生 ImageAll；关联 ADR-069、081、082、083

## 已有、补齐与延期

复用已接受标签 ID 的键集分页、故事项目 v1 的原子保存、统一 30 fps 时间线与
OpenMontage v1.1 / StoryRenderPackage v0.1。第四阶段补齐完整候选的可用性统计、
待审建议的单独计数、近重复覆盖、重新读取变化、同阶段替换约束、锁定冲突，以及从标签
入口实际生成的合成验收。真实照片审片、未知时区 EXIF 重解析、外部地理解析和质量模型延期。

## 产品规则

1. 主体由 active 标签 ID 决定。草稿只纳入该标签 accepted 的静态图片；rejected 不进入。
   待确认计数只表示库中该标签的当前版本 pendingReview 建议和待审上下文候选去重数量，
   不是全部尚未贴标签图片的预测数量。待确认项不进入候选分母或成片。
2. 候选按 `embeddedTimeOldest` 键集遍历到终点，明确请求所有可查询可用性。
   不可浏览的回收记录和库查询本身隐藏的 Photos 缺失历史仍不在分母内；报告说明范围。
   分页可取消并报告已读数量。每次重新生成重新读取当前标签候选和建议；冻结快照摘要
   覆盖候选内容版本、地点、收藏、相似证据、策略和待审计数，不把旧分析套给新素材。
3. `media_created_at_ms` 只来自 ADR-069 的可靠媒体时间；文件夹的无时区 EXIF
   不会被解释成 UTC 或转用文件修改时间。目录目前只存归一化时刻，没有原始时区和
   年/月级精度，UI 按日期展示已知覆盖，并明确来源/精度限制；无可靠时刻的照片在
   时间待确认区，不编造顺序。无 `asset_location` 记录为未读取/未确认；`none`
   记录为已检查无地点；仅坐标没有可分享名称，不猜城市。
4. 早、中、近期按可靠时间跨度划分；每个有素材的时期先保证名额，再考虑连续地点
   首次和回访段，阶段内使用可用性、收藏、像素尺寸和同事件相似簇去冗余。
   A→B→A 保留三个连续段；相似簇只在同一阶段且六小时内抑制，不删除跨时期对比。
   相似索引缺失时明确降级。理由只来自实际选择依据；不宣称清晰度、主体完整度、
   搬家、年龄或完整旅程。
5. 替换限同一可靠时间阶段、同一已确认地点名称（无名称者保持无名称），且必须是
   同一主体快照中的可用非排除照片。无替代时说明约束。替换锁定新素材并把原图加入
   “本故事排除”，防止再生成立刻返回；移除按钮同样表示“本故事排除”。项目保存此集合。
6. 重新生成保留锁定、替换、手动字幕/时长及按稳定章节 ID 记录的手动章节标题；
   即使暂时排除了该章最后一个镜头，标题覆盖也随项目保存，日后该连续段重现时恢复。
   不自动丢弃锁定。
   若保留素材不再属于当前已接受候选、变不可用或内容版本改变，拒绝重新生成并定位
   素材；用户须解锁/排除或重新选择。保留镜头超过 18 个容量则拒绝并显示数目与调整办法。
   60 秒是软目标；用户延长镜头导致超出时显示超出量，可手动缩短、排除或保留较长视频，
   不自动改写锁定时长。旧 v1 项目缺少新的可选快照证据时按未知显示，不改变 Schema
   主版本；新增信息只在 ImageAll 项目中，渲染/任务协议语义不变。

## 验证

合成库跨目录库实际 200 条分页上限，包含接受/拒绝/待审、A→B→A、未知时间/地点、不可用与
同事件/跨时期相似素材。断言就绪分母、稳定选择、编辑再生成与旧项目解码；日常
安装 App 的合成入口须从标签到报告再生成，实际编辑、保存重开、制作并核验成片。
