# ADR-088：主窗口时光故事与可视化素材编排

- 日期：2026-09-21
- 状态：Accepted
- 来源：项目所有者要求取消独立弹窗，通过左侧栏进入类似视频编辑软件的素材拖拽界面。

## 问题与决定

原来的故事 sheet 将素材报告、插件配置和镜头表单混在一起，替换依赖文件名菜单。ADR-084 的自动选片约束还使多章节故事无法补入照片，和手动创作需求不符。

主窗口新增「时光故事」入口；标签菜单转到同一模块。选择主体后在模块内呈现左侧缩略图素材库、右侧素材/成片预览与选中镜头属性、下方横向镜头编排。切换其他模块保留本次会话的主体草稿。保存项目可重新打开。

素材来自当前故事冻结的已确认候选快照，不新增来源权限。照片拖到添加区追加镜头，拖到现有镜头替换，镜头拖到另一镜头前调整顺序，拖到末尾添加区移到末尾。提供按钮及右键操作作为拖拽替代。内部拖拽采用卡片本地坐标与实测卡片边界换算，避免 macOS 分栏宿主造成落点偏移，并显示浮动提示和目标高亮。手动编排不继承原自动模板的 18 镜头选片上限；自动模板仍保持其既有选片策略。已使用、已排除、不可用素材不可重复添加。

手动编排不再受自动规划的同阶段、同地点、单章节限制；允许用户明确使用拍摄时间未知的候选，但仍标注未知，不推断日期或地点。编辑后的 shots 顺序、chapterID 和 chapter.shotIDs 同步维护，空章节移除。锁定和用户编辑标记保留手工选择；显式重新生成仍恢复自动时间顺序，执行前说明此后果。若已手动加入时间未知照片，则保留草稿并说明不能按时间重新生成；手动编辑和导出不受影响。

中央预览、底部时间线固定可见；右侧以镜头、创作、信息三个同级页签承载属性，移除嵌套折叠与重复创作表单。保存、撤销/重做、配乐、制作与导出集中在编辑区顶部。此轮不是完整多轨剪辑器，不增加音轨剪切或自由场景编辑。

## 安全与验证

缩略图复用只读 StoryMediaLoading 边界的独立缩略图方法，生产实现使用 originalAspectThumbnail 缓存通道，按可见素材加载、合并重复请求、最多四路并发并在后台解码至 480 像素；不引入 Photos 写入、云下载授权或来源写入。自动测试只使用合成 fixture，直接 test bundle，不启动生产 composition root。验证跨章节追加、移动、序列化重开、时间线标准化，以及重复/外部/排除候选拒绝。UI 验证先用现有合成运行入口；构建通过后更新已备份的日常 App。

## 2026-09-21 后续产品修订

用户要求一起解决素材加载、信息堆积、按钮层级、固定模板与执行器配置。新项目默认空白自由编排，标题为主体名；片头和章节卡默认关闭。旧项目可逆兼容，optional 字段缺失仍保留既有显示，不静默改写用户项目。提供转为自由编排和片头/章节卡开关。自动模板需显式选用。

创作意图和目标时长只出现一次，目标时长不冒充当前时间线时长。制作方式区分当前编排、可编辑创作、自由场景。Atelier 发布范围改为当前已选照片，26 张是外部制作协议限制，在该方式明确显示，不限制项目选片；原生导出保持可用。请求仍 local-only，Agent-assisted 不伪装成自动导演。

OpenMontage 目录未配置、授权失效、离线、版本和依赖状态分别显示，编辑器内可选择目录并重新检查。此前收尾停用旧守护进程，恢复使用新任务目录，不复用已归档任务根目录。现有 App 不内嵌 Python/Node；执行器启动由本次开发恢复本地运行环境，不自动消费历史队列。
