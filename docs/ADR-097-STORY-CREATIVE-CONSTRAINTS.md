# ADR-097 自动创作建议与明确保护分离

2026-09-23。

问题：手动加入、移动照片会写入 isLocked/isUserEdited；自动创作把任一标记解释为字幕和时长均不可改，空字幕与默认时长也被固定。用户的选材、排序和创作建议不等于精确镜头锁定。

决定：自动可编辑方案保留选材、顺序和章节。意图和目标时长为软建议。新增可选的明确锁定、字幕编辑、时长编辑字段，分别追踪用户动作；仅明确锁定保护整个镜头，修改字幕仅保护字幕，修改时长仅保护时长。加入/移动/换图不新增锁定。手动保护可通过“允许重新优化”主动解除，保留当前内容作为建议；解除整镜头锁定不会默默抹掉字段保护。生成前显示三种保护的数量。

兼容：没有新字段的旧草稿中，“手动编排”且无“用户锁定”的自动锁定不传给导演；旧的非空字幕和非默认时长采取保守保护，因为没有可靠编辑历史，用户可以主动允许重新优化。旧换图自动生成的锁定同样不作为明确锁定；无法区分的历史状态不猜测清空内容。应用新方案时写入明确保护字段，避免模型字幕在第二轮被当成手动编辑。旧 1.0/1.1 插件维持原协议，1.2 自动执行器支持可选的字段保护；模型提示、Python 返回校验、Swift 应用校验保持一致。模型不得突破明确保护。

不自动修改用户已返回的方案，不自动重新发送照片。现有方案来自旧约束，需要用户重新生成才能获得新的节奏建议。

验收：5 项 Swift 定向测试通过（自动方案发布/应用及字幕、时长独立保护；旧草稿保护兼容与 Codable；手动加入/移动持久化；旧协议顺序保护；锁定与路径拒绝）。Python 合成 loopback 模型请求/返回测试通过，包含字段保护冲突拒绝。未发送真实照片、未新增付费调用。构建成功；日常 App 已备份并更新，签名通过，App 二进制与打包导演脚本均与构建产物哈希一致。
