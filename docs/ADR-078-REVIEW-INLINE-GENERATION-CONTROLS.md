# ADR-078：审核工作台内联批量生成控制

- 日期：2026-09-17
- 状态：Accepted
- 授权：项目所有者确认取消常驻生成中心，保留顶部生成入口、运行状态和必要诊断。

## 问题与决定

生成中心常驻占用一整列，批量扫描入口与窗口工具栏重复；独立服务的“尚未检查”状态与 App 内置模型扫描完成状态并列，容易误导用户。ADR-077 修复了滚动边界，但保留侧面板已不符合本次产品决定。

删除侧面板、展开收起按钮和拖动分隔条。审核列表占用内容区完整宽度，保留 ADR-077 的窗口约束和原生滚动条边界修复。顶部搜索栏提供一个“批量生成建议”菜单，按当前能力提供个人模型和标准模型操作；审核概览隐藏窗口工具栏中重复的全库扫描按钮，其他图库位置保留。

菜单明确实际范围：内置个人模型使用选中项（存在选择时）或全部可用来源；服务模型使用顶部所选来源。仅复用既有生成路径，不更改扫描、阈值、模型、照片访问或建议写入语义。

运行、等待、暂停、重试及错误状态内联展示；仅对支持的后台任务显示暂停、恢复、取消等操作。完成和取消结果显示 8 秒后收起，不在进入页面时重新显示陈旧结果。内置模型已有完成通知保留；“活动”增加当前会话内置个人模型状态/最近结果，后台服务任务仍使用既有任务记录。此次不新增跨重启扫描历史存储。

常态不检查、不展示独立本地服务状态。仅在服务模型报服务不可用时提供诊断弹窗。内置模型不可用时引导检查设置，不显示无关服务诊断。

## 验收

构建和签名校验；直接在日常 App 中检查审核概览、批量生成菜单及范围、活动中的现有完成结果、窗口宽度变化和滚动边界。不为布局测试自动触发全库扫描或修改照片，不另建模拟图库。
