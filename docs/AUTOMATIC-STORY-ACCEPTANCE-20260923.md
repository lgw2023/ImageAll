## 现场发现与修复

- 原先创作只是文件发布，缺少自动消费；现在本地守护进程接收任务并启动受限模型创作子进程。
- 创作期间重复提交按钮未禁用：增加持久化状态判定与 UI 防重复提交。
- 应用按钮位于长说明下方：移至说明上方，应用后选中第一镜头便于微调；应用失败时保留面板错误信息。
- 再次提交渲染时旧任务 ID 可能屏蔽新进度：提交前清空旧快照。
- 渲染已运行但下方仍显示“等待”：状态更新时清除过期消息，显示执行器上报百分比。
- 管理目录的“打开成片”误请求再次授权：统一经过原 task-root provider 获取访问权限，保留自选目录授权校验。
