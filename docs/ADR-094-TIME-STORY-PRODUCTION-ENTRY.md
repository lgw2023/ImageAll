# ADR-094：时光故事制作入口与输出画幅

2026-09-22，已实施。

## 问题

顶部“制作设置”仅把检查器切到“创作”，已在该标签时没有可见反馈。右侧混排编排、创作意图、服务连接和请求提交；顶部故事包的横竖选项又容易被误解为全局画幅。原生 MP4 仅支持横屏，自由场景协议仅支持竖屏，各路径的能力并不相同。

## 决定

- 顶部使用“制作视频…”打开独立、可关闭并反复打开的制作面板。检查器保留编排、片头、章节卡、意图与目标时长，并提供同一面板的快捷入口。
- 面板按“制作方式 → 输出画幅 → 制作操作”排列。当前编排和可编辑创作共用本次制作画幅选择；自由场景明确显示竖屏 9:16 及限制，不提供无效横屏选项。切换自由场景不覆盖前两种方式的选择。
- 当前编排的横屏面板提供无需外部服务的直接 MP4 导出。本地制作服务单独分组；停用时所有提交入口禁用，直接导出仍可用。
- 自由场景按钮改为“开始自由场景创作”，可编辑创作使用“生成可编辑方案”并显示所选画幅。创作请求不等同已完成的视频，继续保留读取方案、应用、审片和版本迭代步骤。
- 连接目录和检查连接收进“连接选项”；已就绪时禁用重复启动服务。面板显示现有任务与导出进度、取消和打开成片操作。
- 顶部导出菜单区分“可直接播放”的横屏 MP4 与“交给外部工具继续制作”的故事包。横竖选项仅存在于“导出故事包（非视频）”子菜单。
- 明示制作画幅只用于本次制作，中央仍是当前编排的横屏预览。本轮不变更协议、渲染能力、项目数据格式或原片访问边界。

## 验收

构建通过；用合成数据检查重复打开/关闭、三种方式切换、画幅恢复、导出菜单分组及禁用服务的行为。更新前保存当前草稿并备份日常 App，更新后检查日常版本的制作入口，不提交真实素材制作任务。运行证据另记。
