# ADR-080：确认样本优先，负样本不作为通用起步门槛

状态：已采纳（2026-09-17，项目所有者明确授权完整实施）。

## 决策

标签日常起步只要求至少 2 张确认样本，不要求先凑拒绝记录。保留真实拒绝反馈，不把未标记、忽略或跳过自动转换为负样本。现有样本匹配、学习识别两条路径继续使用确认样本；不改动其训练算法或声称拒绝会自动参与训练。

- 卡片优先直接展示“按样本匹配”“用模型识别”；“正反样本对比（可选）”排在第三位，依然单次点击可达，不折叠。
- 标签总状态只以确认样本判断起步就绪；已有任务优先展示真实任务状态，不被当前样本变化覆盖。
- 训练方法优先样本匹配，其次学习识别；只有两者不可用而正反对比可用时才选择后者。均不可用时仍展示样本匹配作为起点。
- 旧 featureKnn 对比算法仍要求正反各 2 张。该门槛仅属于此可选方法，按钮提示明确另外两种方法不需要拒绝样本。
- 同步空队列提示、训练说明、来源名称与门槛名称，避免标签整体“缺负样本不可用”的误导。

## 边界与兼容

这是移除通用产品门槛，不是让原正反距离公式接收空负样本。保留原打分、任务校验、冻结样本、模型版本、数据库及历史记录。两类分数不混用，也不隐式切换算法。尚未训练的模型仍需通过现有训练入口准备，不在点击建议时悄悄启动训练。历史规格中正反各 2 张规则今后仅适用于 featureKnn。

## 验证标准

- 0、1 张拒绝时，确认样本足够的标签总体 ready，个人路径可用，正反路径仍拒绝；2 张时正反路径可用。
- 已有任务在样本数量变化后保留任务状态。
- 既有两类正样本训练测试、训练文案及选择计划回归通过。
- 构建与签名通过，更新日常 App，实际检查卡片按钮顺序、禁用提示及训练入口默认项。
- UI 检查不启动真实训练或扫描，不修改照片原件。
