# ADR-114：iPhone 导入后统一使用来源导航

2026-10-23，项目所有者明确要求：Mac 获取 iPhone 数据后按普通来源相簿浏览，后台校验和 metadata 不在侧栏单独展示。

## 现状与差异

ADR-109 将已导入来源与设备分享快照分别展示。后者读取手机曾分享的目录投影，
“刷新手机目录”只重读该投影，不执行照片导入。两组入口同时出现，让用户需要区分
传输目录和可浏览图库，也会把设备离线状态误解为本地照片不可用。

## 决定

- 侧栏仅保留「来源」中的「设备名 · 已导入 Mac」，沿用既有照片、视频、相簿导航。
- 移除「设备 · 分享目录」「分享快照」「刷新手机目录」及其在线状态、快照计数。
- 移除主工作区专用快照路由、投影加载状态和五秒在线轮询；正常来源导航不依赖设备连接。
- 分享投影、导入协议、完整性校验、metadata、发布记录及已有导入数据继续保留。
  本轮只收敛主工作区展示，不改导入设置、数据契约或历史记录。

本决定取代 ADR-109 中设备分享入口与侧栏轮询的展示要求，其他预算、保护和验收结论仍有效。

## 验收

- 当前 Xcode 项目构建通过。
- 合成数据的原生 iPhone 来源浏览及重启后本地编辑保留回归通过；直接 XCTest，不启动生产 Photos 测试宿主。
- 界面检查：侧栏保留已导入来源与相簿，不再显示设备分享分组和刷新手机目录按钮。
- 不执行真实照片扫描、传输、修改或历史清理。
