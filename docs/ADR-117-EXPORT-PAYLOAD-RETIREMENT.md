# ADR-117：手机导出载荷的显式可恢复收尾

日期：2026-10-26。状态：已实现，独立 USB 实机与失败恢复验收通过。

手机流式导出已有逐资源释放机制：接收端校验成功后释放该缓存窗口，保证手机空间有界。最终收尾保留这一机制，仅处理同任务残留的导出载荷。Mac 的普通可浏览状态是目录观察，不能授权释放手机载荷。

采用显式收尾请求：同一配对来源通过固定 TLS 连接请求完成回执，Mac 在发布锁内完整校验最终副本和数据库引用，回执绑定任务、清单、来源、主机、设备及本次随机请求值。手机检查实时连接身份及随机值后，持有原导出锁，验证所有权和冻结计划；先同步写入收尾意图，再将登记的临时资源截断为零。保留任务、清单、流记录、来源校验凭据及零长占位文件。恢复必须重新获取新回执；意图禁止重新导出。

只为新所有权版本提供收尾，不扫描或接管旧任务。正常流式窗口已释放的文件可保持不存在；未知文件、链接、对象替换、损坏、活跃导出和不完整意图拒绝处理。每次破坏性操作前重新核对路径身份。中断可重复执行，但不承诺突然断电的硬件持久性。

验收：独立 USB 合成任务的 Mac 暂存收尾后，手机恢复同任务可浏览且新增上传为零；新回执、失效回执、损坏、对象替换、活跃锁及中断恢复的必要测试；手机收尾、重启及重复收尾保持可浏览、零上传。最终副本全量校验与既有内存保护不变。

实现说明：iOS 以规范容器路径打开目录，再通过句柄相对访问子项；macOS 保留从根逐层 no-follow 打开。两端破坏性操作均检查路径和对象身份。显式操作每次取得新回执，常规完成状态刷新仍不读原件。后台自动触发留给下一切片，不扫描旧任务。

证据：`/Volumes/SSD1/.codex-builds/USB-P4-PhoneCleanup-20261026/Evidence/REPORT.md`。22 项有效协议测试、独立 SIGKILL/新进程恢复、真实发布副本损坏拒绝、HTTP 来源/随机值绑定及任务路径绑定通过；16 MiB 同一 USB 任务完成 Mac/手机收尾及重启后零上传。该规模用于生命周期验收，不替代 4 GiB 性能测试。
