# ADR-045：按来源相似索引（预热邻域，加速种子检索）

> 状态：已决定并实施中（2026-07-28，项目所有者对话批准）  
> 相关：`docs/LIBRARY-SLIMMING-SPEC.md`、ADR-044  
> 背景：大来源（数万张）上每次种子检索若对全宇宙加载 Feature Print 并暴力比对，即便向量已缓存仍过慢。

## 决策

### LS-P10：按来源显式初始化相似索引

- 用户可在「图库瘦身」对**当前选中的单个来源**发起「初始化相似索引」。
- 初始化是持久 Job：补齐该来源缺失的 Feature Print（复用既有 content-revision 缓存），写入来源级
  **Feature Print LSH 邻域桶**；桶内再按现有 `τ_fp`（Feature Print max L2）做连通分量，形成可浏览的
  **软簇**（无监督预聚类的产品呈现）。
- 索引绑定：`source_id` + Feature Print 模型身份 + 策略版本 + 构建时阈值快照。身份或策略不兼容则视为
  stale，需重新初始化；单资产 `content_revision` 变化只使该成员过期，查询时跳过并回退局部实时路径。

### LS-P11：种子检索优先走邻域，而非全宇宙暴力比对

- 当种子检索的宇宙资产**全部**属于「索引就绪」的来源时：
  1. 相同档仍走指纹路径（哈希索引，不依赖 LSH）；
  2. 相似档：用各种子的 Feature Print 定位 LSH 桶及 Hamming 距离 ≤ 1 的邻桶，合并候选；
  3. 仅对「种子 ∪ 邻域候选」加载/比对 Feature Print 与 DINOv2，再按既有 Top-K / `τ_sim` 成簇。
- 任一宇宙资产所属来源无就绪索引，或索引 stale：完整回退到现有全宇宙粗筛路径（正确性优先）。
- 分析任务结果仍按任务永久保存；来源索引是**加速层**，删除分析记录不删除来源索引。

### 非目标（本轮）

- 不自动对全部来源后台预热；
- 不做跨来源统一 ANN 服务、不引入 FAISS/外部进程；
- 不用硬簇单点命中替代邻域（禁止「只查所属簇、不扩邻桶」造成漏召回）；
- 不改变相同档定义，不改变回收站语义。

## 后果

- 新增 migration **v023** 表：`source_similarity_index` / `source_similarity_bucket_member` /
  `source_similarity_cluster_member`。
- 图库瘦身 UI 增加来源索引状态与「初始化」入口；种子检索在就绪时显著缩小向量加载与比对集合。
- 首次初始化仍可能耗时（主要是补 Feature Print）；完成后同来源反复种子检索应明显加快。
