# ADR-101 · 任务目录授权与可见反馈

2026-09-23，修复。

用户报告重新选择任务目录后仍显示授权失效。代码检查确认：制作页使用临时设置对象打开目录选择器，其保存错误未传回当前界面；存储层也把所有 stale bookmark 直接视为失效。

选择目录时先开启所选 URL 的 security scope，再创建可写书签；验证新书签可解析、非 stale 且可重新开启 scope 后才替换旧授权，失败保留原任务目录。App 自有目录不需要外部授权。读取旧书签时，只在原授权仍能开启的情况下续期，不静默切换任务队列。

目录选择返回成功、失败、取消三种结果。制作页显示已授权路径或具体错误，成功后刷新连接；授权成功不等于后台服务已启动。连接选项常驻展示，不再使用 DisclosureGroup。

验证使用临时目录与书签替身，覆盖有效旧授权续期、失败保留旧书签、再次授权成功、scope 成对释放；另回归无授权的 App 自有目录与损坏旧书签不回退。真实用户目录的系统授权不由该替身测试替代。
