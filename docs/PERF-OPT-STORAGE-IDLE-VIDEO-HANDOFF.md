## 3. 切片与停止位置

### 切片 A — 视频/非图片永不入库（先做）

**目标**

1. 文件夹枚举在确认为普通文件后，对明显非图片（含视频扩展名/UTI）直接 `.ignored`，避免无谓分类成本；
2. 分类器与 Photos 适配器保持/加固“只静态图”；
3. 启动或 catalog ready 后执行一次性清除：删除目录库中视频类 `asset` 及其 `asset_tag_decision`（先删 RESTRICT 决定，再删 asset，依赖 CASCADE 清理 fingerprint/派生缓存行等）；
4. 测试覆盖：枚举跳过 `.mov/.mp4`；清除用例含带标签的视频行后库中为零。

**不做**

- 不改存储迁移；
- 不做空闲预热；
- 不访问 `/Volumes/HDD2` 或真实 Photos 库。

**停止**：切片 A 测试与 Debug build 通过后停止，交复审；不进入 B/C。

### 切片 B — 空闲 3 分钟默认预热

**目标**

1. 设置项「空闲时预生成缩略图」默认 **ON**；
2. 无指针/键盘/滚动等交互满 **180s** 后，以低于浏览优先级的并发预热当前来源（或当前查询）尚未缓存的网格缩略图；
3. 任意用户交互立即取消/挂起预热，把门控让给视口加载；
4. 遵守既有 20 GiB 配额与 memory-fallback；预热失败不打扰主 UI。

**不做**：不改存储迁移；不引入全库强制预热为默认。

**停止**：B 完成后停止，交复审。

### 切片 C — 整包存储迁移任务 + 进度

**目标**

1. 用户选择外置根后，仍可要求重启（或进入专用迁移态）以关闭正式库句柄；
2. 迁移过程展示**任务 + 进度**（至少：阶段文案、已复制字节/总字节或文件计数、可取消若安全、失败可重试）；
3. 复用/改造 `ExternalAppStorageMigrator`，把同步盲等改为可报告进度；
4. 设置页在迁移中/待迁移/完成态可读；成功后写入既有 completion marker，其后启动走外置根。

**约束**

- 迁移不得在目录库已打开写入时原地搬移活跃 SQLite；
- 不破坏 bookmark/security scope；
- 不 push；真实盘烟测仅在所有者明确授权后。

**停止**：C 完成后本交接单关闭。

## 4. 验收门（汇总）

- 切片 A：视频夹具不进 `available`；清除后视频 asset/决定为 0；既有图片标签不受影响。
- 切片 B：默认 ON；180s 后有预热调用证据（测试用可注入时钟/阈值）；交互打断可测。
- 切片 C：选择外置根 → 迁移 UI 进度单调前进 → 完成后 AppPaths 指向外置 Application Support/Caches；中断/冲突仍 fail-closed。
- 全切片：零 `/Volumes/HDD2` 访问；不提交 `user/`；作者身份符合 AGENTS.md。

## 5. 风险与说明

- `asset_tag_decision` 对 `asset` 为 `ON DELETE RESTRICT`，视频清除必须先删决定。
- 用户确认本阶段**不保留**视频上的标签事实；清除不可逆（除用户自有备份/可移植导出）。
- 启动期大容量整包 copy 仍可能很慢；进度 UI 是必要可观测性，不能假装成瞬时完成。
