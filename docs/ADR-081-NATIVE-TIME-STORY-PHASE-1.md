# ADR-081：原生「时光故事」第一阶段

- 状态：Accepted
- 日期：2026-09-18
- 范围：ImageAll 原生 macOS App
- 相关：ADR-041、ADR-045、ADR-055、ADR-056、ADR-069、`LOCAL-TEST-DATA-SAFETY.md`

## 目标与边界

第一阶段从一个明确的 active 标签 ID 创建唯一模板「成长与足迹」。生成器只使用 catalog
中已经存在的人工 accepted 标签、可靠媒体拍摄时间、地点、收藏、尺寸、可用性及兼容的来源相似簇，
交付可解释、可编辑、可持久化并可导出 MP4 的原生 Mac 闭环。

标签名称和主体类别都只是显示信息；实现不得硬编码「板栗」，也不推断主体是人、宠物或物品。
本阶段不做自然语言主题、漏标识别、生成式视频、旁白、公共素材、复杂地图动画、自动卡点、
全库质量重评分或 Web/iOS 编辑。

## 决策

### TS-P1：候选快照与元数据读取

1. 候选必须通过现有 `AssetCatalogQueryPort` 按 `embeddedTimeOldest` 完整键集分页取得，过滤条件为
   明确标签 ID 的 accepted 决定、静态图片；不得使用当前网格、地图弹窗或任何有界 UI 集合。
2. 冻结每个候选的 asset ID、content revision、媒体时间、可用性、尺寸、收藏、地点来源与分享级
   地点名，并以这些内容的稳定摘要作为 snapshot ID。生成草稿期间不解码候选图片。
3. `media_created_at_ms` 是唯一确定叙事顺序的时间，遵守 ADR-069；文件修改时间不参与排序。
   时间未知素材进入待确认区，不进入确定章节。无 GPS 的素材继续保留。
4. 地点覆盖只统计 catalog 已确认的 `place.canonical_name`。只有坐标而未确认可分享地点名时记作
   「已定位但名称未确认」；没有 `asset_location` 行时记作「元数据未确认」，不得冒充「没有地点」。
5. 就绪摘要保存匹配数、可靠时间范围、时间未知数、已命名地点数、地点元数据未确认数、
   不可用数和相似筛选状态。

### TS-P2：确定性章节与选片

1. 确定时间素材按 `(media_created_at_ms, asset_id)` 排序，并先划分早期、中期、近期三个时间阶段；
   阶段存在素材时各自至少保留一个名额，再在阶段内稳定评分。
2. 评分只使用阶段代表性、收藏、分辨率、可用性、地点变化和多样性。相同输入、策略版本和
   编辑约束必须得到相同结果。
3. 地点章节按时间连续游程形成，保留 A → B → A。无分享级地点名的素材不会继承上一张地点；
   地点证据不足时使用时间阶段章节。
4. 兼容且 ready 的来源相似簇只在同一时间阶段/近邻事件内抑制重复；不使用簇 representative 作为
   最佳照片，也不跨时期消除成长对比。相似索引缺失或陈旧时允许退化并写入说明。
5. 每个镜头持久保存一条或多条短理由，如「早期代表」「地点变化」「收藏照片」。目标约 60 秒，
   素材不足时缩短，不重复素材填时长；地点或时期无法全覆盖时在草稿摘要中说明取舍。

### TS-P3：项目格式与编辑合并

1. 项目是 `Stories/v1/<project-id>.imageallstory` 版本化 JSON，包含主体标签、候选 snapshot、候选
   asset/content revision、章节、镜头顺序、字幕、停留时间、完整画面参数、锁定/排除、用户修改标记、
   配乐书签/路径（仅用户选择文件）、模板和策略版本。
2. 保存使用同目录临时文件写入并原子 replace/move；关闭 App 后可重新打开。项目不保存照片像素，
   不把 MP4 当成项目本体。
3. 替换、锁定、移除、章节标题和停留时间是首期编辑面。重新生成保留锁定、排除和用户改过的字幕、
   时长、章节标题；其他镜头可由同一冻结候选快照重新规划。
4. 内容版本变化或素材缺失在导出前逐镜头检查并返回可定位的镜头序号/asset ID，不静默换图。

### TS-P4：本地渲染与发布

1. `TimeStoryRendering` 是规划/编辑与渲染的边界；首版 `AVFoundationTimeStoryRenderer` 在本机生成
   H.264 MP4，固定 1920×1080、30 fps，使用同一镜头时间线计算转场重叠后的总时长。
2. 每张照片通过现有授权媒体读取路径按正式预览尺寸读取，不直接遍历 Photos Library，不使用网格
   缩略图。画面默认完整 fit，以模糊/暗化背景填充；只做不会裁掉主体的轻微背景运动，前景不做盲目推近。
3. 支持淡入淡出、简洁中文字幕和可选本地配乐；无音乐同样可导出。配乐只读取用户选择的文件，
   不上传、不写源文件。
4. 渲染先写 App 自有临时文件；成功并通过可播放检查后才原子发布到用户目标。取消/失败删除临时产物，
   不覆盖已有成片，也不修改项目或源照片。进度和取消由同一渲染会话提供。

## 入口与体验

- 标签行的管理菜单增加「创建时光故事…」，直接传入该标签 ID。
- 创建后打开原生故事工作区并立即生成草稿，展示就绪摘要、章节、镜头、理由与实际时长。
- 工作区支持替换、锁定、移除、章节标题、停留时间、保存、重新打开、重新生成、选择配乐和导出。
- 现有故事从故事工作区的项目列表重新打开；不新增通用 Agent 或插件入口。

## 验收

自动化只使用测试创建的临时数据库、合成图片/音频和临时目录：

1. 多时期、多地点 → 生成 → 编辑保存 → 重开 → 导出可播放 MP4。
2. 回归覆盖早期稀疏/近期密集、A → B → A、早期无 GPS、未知时间待确认、跨时期相似图保留。
3. 重新生成保留锁定、排除和用户修改。
4. 缺失/版本变化可定位；取消/失败不破坏项目、源图片或已有导出。
5. 使用 `AVAsset`/`ffprobe` 核验 1920×1080、30 fps、时长；抽查片头/中段/片尾/转场帧，
   验证中文、方向、无意外黑帧和明显裁切；有音乐和无音乐各一次。
6. 构建后保留旧日常 App 的可恢复副本，更新日常 App，并在不读取受保护真实素材的前提下验证入口和
   工作区界面。真实图库素材质量验收需要新的明确只读人工授权，不能由合成验收替代。

## 明确延期

- 年龄、搬家、常住地和完整旅行路线推断；
- 人脸/主体安全裁切与新的美学模型；
- 复杂地图、旁白、自动卡点、多模板、跨端同步；
- 对没有 canonical place 的 GPS 反向地理编码（首期显示未确认）；
- 真实图库的主体选片质量由用户人工验收，算法通过不代表用户认可。
