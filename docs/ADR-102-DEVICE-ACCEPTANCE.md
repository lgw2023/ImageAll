## 按界面执行

| 步骤 | 操作 | 必须看到的结果 |
| --- | --- | --- |
| 1. 配对 | 在 Mac 设置核对 Host 当前状态；经确认启用后开始配对。手机“Mac 图库”使用“扫描 Mac 配对二维码”。 | 手机连接成功，Mac 设备记录对应本次 iPhone。USB 连接本身不证明网络 Host 已连通。 |
| 2. 接收目标 | Mac“选择网络接收目录”，选择上述 receive 目录。 | 页面明确显示网络接收已启用；只保存目录但 Host 未运行不算通过。 |
| 3. 明确范围 | 所有者在手机手动选入测试项，打开“待分享”。 | 已选数量、媒体类型与授权一致；不使用全选。 |
| 4. 同步目录 | 点击“同步目录与整理信息到 Mac”。 | Mac 可看到该 iPhone 的所选目录；手机提交成功且没有未解决冲突。目录接收不等于原件接收。 |
| 5. 导出并上传 | 手机“生成所选项目的本机归档包”，检查不可用资源，再点“上传已校验归档到 Mac”。 | 归档完整、没有不可用资源；Mac 出现已接收批次，项目数匹配。缺资源时保留失败结果，不下载云端资源补齐。 |
| 6. 入库 | Mac 对该接收批次点“入库并对账”，再点“核查 Mac 归档”。 | 同一迁移批次完整性和账本核查通过；记录媒体数、资源数、总字节与清单摘要。 |
| 7. 可用性 | Mac“在 App 中预览”，检查照片及视频；如确有编辑版／配对视频，切换可用资源。 | 图片可显示，视频可播放；核对原始名称、尺寸、时长和元数据覆盖。不以原件可开证明所有编辑效果或 Live Photo 动态呈现。 |
| 8. 来源与尾部 | 手机再次同步并处理冲突；对同一归档“生成并上传验收检查点”。Mac 对同批次再次“入库并对账”。 | 逐资源来源复核与事实水位通过；若来源、权限或范围变化，记录拒绝原因并重新准备，不能绕过检查。 |
| 9. 独立恢复 | Mac“验证独立恢复”，选新建空目录。 | 新 catalog、媒体资源和事实逐项核查通过；保留恢复结果供人工检查。 |
| 10. 范围回执 | 条件满足时“生成所选范围回执”，随后“复核回执”。 | 当前回执复核通过，并且范围仅为本次选中项。不能写为整机迁移完成或据此清理手机。 |

若需要验证标签／集合／收藏目标双向编辑，先明确只修改测试项的 ImageAll 整理信息，再另记一次往返结果。仅观察默认空事实，不计入双向编辑和冲突验收。
