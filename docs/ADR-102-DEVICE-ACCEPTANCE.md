## 相册权限覆盖验收

- [ ] 完整照片权限：所选项目的可访问用户相册成员／文件夹路径与手机一致；仍不代表空相册或全部相册已迁移。
- [ ] 有限照片权限：媒体可归档，Mac 明确显示来源相册不可读取；入库和独立恢复保持此缺失原因，不能生成相册完整性验收或完成回执。
- [ ] 导出期间完整／有限／拒绝权限发生变化时停止，不把不可见的相册变成空相册。
- [ ] 需要相册完整性验收时，用户自行决定是否授予完整照片权限并重新生成归档；旧的有限权限归档不能原地改写为完整记录。

## 显式相册目录验收

在获得测试项复制及目录元数据范围授权后，开启默认关闭的“保存可访问用户相册目录（含空相册）”。该选项要求完整照片权限；关闭时维持原所选成员快照。

- [ ] 使用含空相册、空文件夹、嵌套相册和有未选成员相册的授权测试目录。确认层级、名称、来源顺序和可见成员总数一致。
- [ ] 没有选中的媒体不进入传输包；有未选成员的相册不显示为“空相册”。
- [ ] 旧 Mac 缺少目录版本能力时在传输前拒绝；不静默丢弃目录继续发送。
- [ ] 导出期间或来源验收前改变目录时拒绝旧快照；原包保持不变，按新快照重新准备。
- [ ] Mac 展开“来源用户相册目录”，核对所有节点；独立恢复后目录相同，来源 Photos 相册保持不变。
- [ ] 仍以所选范围签发回执；目录完整不代表未选媒体已迁移，也不包含智能相册规则。

## 逐资源入口的附加验收

此入口仍受上面的测试项复制授权和 Host 配对范围前提约束。用“所选项目逐资源传到 Mac（减少暂存）”代替步骤 5 时：

- [ ] 确认 Mac 宣告逐资源校验能力，并在先同步目录后确认来源安装身份。缺少身份确认的旧 Host 应在发送媒体前拒绝，新手机的整包上传也必须使用已更新的 Mac。
- [ ] 保持前台，验证照片和视频逐项传输后手机暂存释放，Photos 原件不变；手机仍需能容纳单个最大资源。
- [ ] 整包和逐资源上传期间分别切到蜂窝／断网：后续分片停止，界面报告失败或暂停；恢复 Wi-Fi 后重试原批次，接收 offset 保留。核对系统蜂窝用量和真实任务行为，不以合成请求属性测试代替此项。
- [ ] 中途暂停，再按同一范围重试，核对迁移 ID 不变、已接收 offset 继续、清单未被新快照替换。
- [ ] 缩小权限或改选范围时停止原批次，不把未复制项目静默当作完成。
- [ ] Mac seal、入库和独立恢复的资源数、总字节、清单和事实摘要一致。
- [ ] 若触发批次容量上限，提高上限后原 migration ID 和 offset 继续；调低上限不删除已接收内容。磁盘实际空间不足仍必须停止，不能通过提高额度绕过。

步骤 8 在逐资源入口中使用“查找逐资源批次以继续来源验收”，选择对应迁移 ID 的“生成并上传来源检查点”。必须先重新校验 Mac 当前媒体副本，再核对手机全部所选来源资源和同步状态，之后向同一批次提交事实侧车。

- [ ] App 重启后仍可找到同批次记录；配对、来源或范围不符时拒绝。
- [ ] 本机待同步／冲突未清、来源变化或资源不可本地读取时，不提交检查点。
- [ ] 成功后 Mac 再次入库、核对新的来源校验时间和水位，继续步骤 9–10。

以上仍未作真机验收，不能以重新生成另一个迁移 ID 的归档冒充同批来源验收。旧版未保存记录或 ACK 丢失时，应在原来源、范围和配对一致的条件下重试原传输取得记录。

## 独立备份入口验收

本节需要另外明确授权备份复制范围及目标空目录；已有安装调试或迁移许可不自动扩展到另一个磁盘。此前的隔离恢复结果仍不自动成为独立备份证明。

- [ ] 所选范围回执及共享水位当前有效后，在 Mac 选择“创建并核验独立备份”，明确选择另一设备上的空目录。
- [ ] 同一卷的不同目录必须拒绝；同一底层 USB 设备的分区／LUN 不能因为卷 UUID 不同而通过。网络、虚拟或未知存储应明确拒绝，不使用人工跳过按钮。
- [ ] 在沙盒 App 中确认存储解析可用；终端只读探测成功不替代沙盒运行证据。
- [ ] 复制后照片／视频／整理事实／相册目录在独立 catalog 重建并复核；手机原件及第一份归档保持原样。
- [ ] 断开目标或更换卷、修改备份字节／目录后，复核应失败。此前历史记录保留，不显示当前通过。
- [ ] App／系统重启后重新解析物理依赖，不信任旧 registry ID；不因新 ID 直接认定新设备或跳过字节核查。
- [ ] 此入口不进行手机清理。未来清理还需再次核验备份、手机来源状态、收藏保护和前台第二次确认。

## 迁移产物的瘦身保护验收

只在单独授权的可丢弃合成来源执行破坏性验收，不以真实照片目录验证以下步骤。

- [ ] 将归档、恢复或备份目录放在已接入的合成文件夹来源下，相同检测结果中涉及副本的组不得产生自动清理计划。
- [ ] 先生成普通重复组计划，再将其中一个成员目录登记为迁移目的地，执行旧计划应被拒绝，两个原文件均保留。
- [ ] 直接选择受保护文件执行回收或直接删除时，显示迁移保护原因，文件字节与位置均不变；相同前缀的普通兄弟目录不受误伤。
- [ ] 故障中断恢复／备份复制并重启，部分产物仍受保护；不得凭预留或标记显示“备份完成”。
- [ ] 整体搬移恢复目录后，通过另一合成 catalog 接入，目录标记仍阻止清理；归档改名后检查目录 bookmark 的定位行为。
- [ ] 断开包含保护目录的卷，无法解析 bookmark 时清理应保守失败；重新接入后复核，禁止自动移除保护记录。
