# Web Companion 与 Mac 端功能对齐规格

> 状态：实施中
> 更新：2026-08-06
> 决策来源：`docs/ADR-048-MAC-HOST-WEB-COMPANION.md`

## 目标

让用户在网页端完成 ImageAll 日常工作时，感觉仍在使用 Mac 端：信息层级一致、操作语义
一致、状态不会因后台刷新丢失，且 Host 是唯一数据与写操作权威。

“对齐”不等于在浏览器复制 AppKit / SwiftUI 控件。网页应复用 Mac 端的任务名称、决定
语义、快捷键和视觉层级，并为触控和窄屏提供等价操作。

## 不可退让的交互契约

1. 普通点击选择单项；Command 点击增减选择；Shift 点击连续选择；Command-A 全选当前
   已载入结果；空白区域拖动可框选。
2. 方向键按网格移动，Page Up / Page Down 按可见页移动，Space 打开或关闭预览。
3. 照片与视频是两个独立工作会话，分别保留来源、筛选、搜索、排序、分页、选择和滚动
   位置。
4. 来源、筛选、搜索或排序改变时才重置分页。Host 事件、账号轮询、手动刷新和标签写入
   必须保留已载入窗口与滚动上下文。
5. 审核快捷键与 Mac 一致：P 确认、X 拒绝、U 稍后。U 只把当前项移到本次队列后面，
   不清除或写入标签决定。
6. 单选检查器显示单张资产详情；多选检查器显示所有活动标签的确认、拒绝、未决定聚合
   状态，并允许直接批量决定。
7. 浏览器只保存非敏感工作区偏好。账号密码、配对令牌和长期认证材料不得写入
   `localStorage`、URL 或日志。

## 能力边界

| 类别 | 网页行为 | 例子 |
| --- | --- | --- |
| Web 直接完成 | 调用 Host 权威 API，网页显示真实结果 | 浏览、筛选、多选、标签、审核、任务控制 |
| Web 发起，Mac 确认 | 网页创建请求，Mac 展示原生授权或风险确认，结果回传网页 | 选择新来源、Photos 授权、受保护空间写入 |
| Mac 保留 | 网页解释限制并指向 Mac，不提供伪入口 | 系统权限授予、Host 网络与账号白名单配置 |

任何写操作都必须遵循现有原子性、幂等、来源能力和照片保护契约；不得为了网页功能绕过
Mac 端校验。

## 本轮实现范围

本轮修改 Web Companion 静态资源、Remote 协议/Host 路由与对应测试、本规格和 ADR-048；
图库瘦身接入已有分析服务的权威投影、受限命令和可恢复回收站，来源管理接入“Web 发起、
Mac 原生确认”的异步请求；应用存储维护接入脱敏用量投影和 Mac 原生选择/确认；网页不直接访问
文件系统或 Photos Library，所有恢复、协调和永久删除仍由 Mac 既有领域服务执行。

新增的工作区能力包括：

- 照片/视频分段切换和各自会话状态；
- 九档网格密度、侧栏/检查器显隐；
- 标签导航、无标签入口、检查器标签搜索和多选标签聚合；
- 单张与多选检查器按 Host 标签组分段和折叠；标签主体复用 Mac 的左键确认、右键清除语义，
  同时保留显式三态按钮，并在折叠或异步写入后按稳定 ID 恢复焦点；
- 单张检查器从 Review 仓储投影该资产全部待审 AI 建议和四轨来源，默认显示前 5 条并可展开；
  “属于/不属于”继续复用原子标签决定，成功后由 Host 详情决定哪些建议消失；
- Command/Shift/Command-A、方向键、Page Up / Page Down、Space、空白框选；
- Command-K 命令面板、快捷键说明和资产右键菜单；
- 审核正式 API 路径与 P/X/U；
- Intersection Observer 自动续页、按事件类型合并刷新，以及配对会话的 15 秒一致性兜底轮询；
- 图库与审核队列按稳定 ID 原位协调，手动刷新、后台刷新和写入后刷新都保留已载入窗口。
- 新增与 Mac `GalleryOverviewView` 同源的“图库总览 / Library Atlas”：四项关键指标、照片/
  视频媒体账本、精确摘要覆盖、来源构成、可用状态、正样本标签和最近 16 个年份均由 Host
  `/v1/gallery-overview` 一次性只读投影；来源、标签和媒体卡可下钻回真实图库筛选，不在浏览器
  复制统计逻辑或伪造结果。
- 检查器请求按工作区与请求代次验收；无变化的静默轮询不重载详情，瞬时失败进入合并重试。
- 标签侧栏按 Host 标签组投影分组；管理面板支持标签重命名、移动分组、归档，以及标签组
  新增、重命名和删除，所有写入均使用幂等操作 ID。
- 标签与审核决定成功后分别显示各自最近一步撤销；两个 Host 槽互不覆盖，均只对当前进程中的
  本通道最近一步有效。浏览器在传输失败后重试同一次撤销时复用原操作 ID，不把旧幂等账本迁移成
  不可验证的新格式。
- 审核首页按标签显示待审总数、建议来源构成、已确认/已拒绝样本数和任务状态；照片/视频
  与当前来源范围由 Host 权威查询，从总览进入队列后后台刷新不会覆盖队列摘要。
- 账号模式只拉取进入或接近可视区的缩略图，并把检查器大图请求设为高优先级；点击照片时
  先从当前缩略图生成本地渐进占位，大图完成后原位替换，不再用长时间空白转圈阻塞详情。
- Host 新增受保护的视频媒体路由，完整响应和单段 HTTP Range 均以 256 KiB 有界分块发送，
  返回真实视频 MIME、`Accept-Ranges`、`Content-Range`，并正确拒绝越界或多段 Range。
- 文件夹视频复用来源访问租约和 no-follow 文件描述符；Photos 视频只通过 PhotoKit 请求本机
  原始 AV 资源 URL，每个响应独立持有并在完成、失败或取消后释放资源。
- 检查器使用浏览器原生视频控制器播放、暂停和定位；网格增加“适应/填充”宽高比切换。
- 普通图库视频卡常驻播放标识和时长；细指针停留 180 ms 后用同一受保护媒体路由静音循环播放。
  页面同时只保留一个悬停播放器，离开、滚动离屏、切换媒体、进入单图、窗口失焦或退出即释放；
  触控与减少动态效果环境不自动播放，悬停不改变选择、分页、检查器目标或滚动位置。
  账号 Basic 仅通过不缓存内容的同源 Service Worker 内存桥接到媒体 GET/HEAD，不进入 URL
  或持久存储；Chromium 原生视频请求缺少 `clientId` 时回退询问同源受控窗口，并以同源模式
  重建请求，避免 `no-cors` 剥离 `Authorization`。
- 后台增量刷新若仍是同一视频和同一内容版本，会复用现有 `<video>` 实例，保持播放/暂停和
  定位进度，不因账号轮询重载媒体。
- 单张检查器补齐视频时长与文件大小，和既有来源、相对位置、媒体、格式、尺寸、拍摄时间、
  修改时间、可用状态共同使用 Mac `AssetInspectorDetail` 权威投影；网页不接收绝对路径。
- 检查器新增“在 Mac 上用‘预览’打开原图/用系统播放器打开”动作，受保护的同源 POST 只
  委派 Mac 现有只读原始资产打开器，不提供浏览器下载或绕过来源授权。
- 新增训练工程只读工作台：按照片/视频和方法读取 Mac `TrainingWorkspacePort` 的真实 Run 与
  三种模型槽位，左侧记录、右侧台账详情和移动端上下分栏沿用 Mac 信息结构；任务事件与
  账号轮询保留当前筛选和选中 Run。
- Host 在训练投影边界移除历史 JSON 中可能含本机路径/书签/locator 的字段，并拒绝把绝对
  artifact 引用发送给网页。
- 新增训练配置与启动命令：Host 返回可训练标签、正反样本数、活动来源和方法可用性，并在
  接收任务时再次执行 Mac 端样本门槛、媒体隔离、范围与单运行校验；相同 `operationID` 重试
  只执行一次。
- 网页“新建任务”面板沿用 Mac 的方法、标签、来源/当前选择和提交确认层级；个人模型继续
  复用现有训练快照、Embedding Cache 与 Centroid / AdamW Rebuilder，任务活动原位显示在
  Run 工作台。网页不接触原始训练文件，也不以本地状态伪造任务成功。
- 个人训练活动只显示 Host 返回的取消动作，取消请求落到同一个 Rebuilder 并返回取消终态；
  Feature Print Run 可打开关联后台任务，建议任务的暂停/继续/取消走审核领域端口，继续时
  唤醒 Host Runner。
- 失败或取消 Run 提供重新配置入口。可验证的历史标签会预选；旧记录缺少标签 ID 时保留原
  方法但清空标签，强制用户重新选择后才能提交。
- 普通图库选区补齐 Mac 的“准备特征”和“查找相似”工具。特征准备复用同一
  `AppSelectedAssetEmbeddingCaching`，Host 逐项复核媒体类型与 content revision，网页只显示
  生成、缓存命中、仅云端和失败计数，并可取消；相似项直接以冻结选区启动既有瘦身种子分析。
  宽屏批量栏、窄屏多选检查器与 Command-K 命令面板提供同名入口。
- 新增世界地图工作区：Host 通过 `/v1/world-map/snapshot` 和 `/v1/world-map/selection`
  投影 Mac 现有 `WorldMapCatalog` 聚合与同桶照片；浏览器复用 App bundle 内的 MapLibre / deck.gl /
  Natural Earth 资源，不从 CDN 执行代码，也不接收路径、locator 或 PhotoKit identifier。
- 地图 iframe 只允许同源嵌入，根 Web 页面继续禁止被嵌入。相机停止后以 240 ms 合并视口查询，
  请求代次拒绝过期响应；点击照片塔载入地点卡片，缩略图和全屏预览继续走受保护媒体路由。
- 网页按 Mac 原有层级补齐“更新照片位置”面板：`/v1/world-map/location-backfill` 投影每个来源的
  状态、覆盖率、已定位/无坐标计数与 reconcile 进度，`.../requests` 以 operation ID 幂等开始、
  重试或取消。打开地图、打开/关闭面板和轮询均不隐式启动或取消；Host 只读来源元数据并仅更新
  ImageAll 自有目录。
- 网页补齐 Mac 的“补全地点”面板：`/v1/world-map/place-tags` 只读本地标签缓存，
  `.../requests` 仅在用户显式提交时搜索地点描述或确认 Host 候选。浏览器不接收照片、路径、
  Photos identifier 或资产 ID；Host 继续执行 Apple 地图→OpenStreetMap 回退、候选校验、GPS 优先
  和目录事务。自动化只用合成目录投影与合成浏览器 iframe，不读取受保护真实图库。
