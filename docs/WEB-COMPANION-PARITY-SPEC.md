# Web Companion 与 Mac 端功能对齐规格

> 状态：实施中
> 更新：2026-07-30
> 决策来源：`docs/ADR-048-MAC-HOST-WEB-COMPANION.md`

## 目标

让用户在网页端完成 ImageAll 日常工作时，感觉仍在使用 Mac 端：信息层级一致、操作语义
一致、状态不会因后台刷新丢失，且 Host 是唯一数据与写操作权威。

“对齐”不等于在浏览器复制 AppKit / SwiftUI 控件。网页应复用 Mac 端的任务名称、决定
语义、快捷键和视觉层级，并为触控和窄屏提供等价操作。

## 不可退让的交互契约

1. 普通点击选择单项；Command 点击增减选择；Shift 点击连续选择；Command-A 全选当前
   已载入结果；空白区域拖动可框选。
2. 方向键按网格移动，Page Up / Page Down 按可见页移动，Space 打开或关闭预览。
3. 照片与视频是两个独立工作会话，分别保留来源、筛选、搜索、排序、分页、选择和滚动
   位置。
4. 来源、筛选、搜索或排序改变时才重置分页。Host 事件、账号轮询、手动刷新和标签写入
   必须保留已载入窗口与滚动上下文。
5. 审核快捷键与 Mac 一致：P 确认、X 拒绝、U 稍后。U 只把当前项移到本次队列后面，
   不清除或写入标签决定。
6. 单选检查器显示单张资产详情；多选检查器显示所有活动标签的确认、拒绝、未决定聚合
   状态，并允许直接批量决定。
7. 浏览器只保存非敏感工作区偏好。账号密码、配对令牌和长期认证材料不得写入
   `localStorage`、URL 或日志。

## 能力边界

| 类别 | 网页行为 | 例子 |
| --- | --- | --- |
| Web 直接完成 | 调用 Host 权威 API，网页显示真实结果 | 浏览、筛选、多选、标签、审核、任务控制 |
| Web 发起，Mac 确认 | 网页创建请求，Mac 展示原生授权或风险确认，结果回传网页 | 选择新来源、Photos 授权、受保护空间写入 |
| Mac 保留 | 网页解释限制并指向 Mac，不提供伪入口 | 系统权限授予、Host 网络与账号白名单配置 |

任何写操作都必须遵循现有原子性、幂等、来源能力和照片保护契约；不得为了网页功能绕过
Mac 端校验。

浏览器完成端到端验收；`待协议` 表示 Host 还没有足够的远程命令或投影。

## 本轮实现范围

本轮只修改 Web Companion 静态资源、对应 Remote 静态契约测试、本规格和 ADR-048，不修改
正在并行开发的图库瘦身、回收站、数据库或 Photos 写入代码。

新增的工作区能力包括：

- 照片/视频分段切换和各自会话状态；
- 九档网格密度、侧栏/检查器显隐；
- 标签导航、无标签入口、检查器标签搜索和多选标签聚合；
- Command/Shift/Command-A、方向键、Page Up / Page Down、Space、空白框选；
- Command-K 命令面板、快捷键说明和资产右键菜单；
- 审核正式 API 路径与 P/X/U；
- Intersection Observer 自动续页、按事件类型合并刷新，以及配对会话的 15 秒一致性兜底轮询；
- 图库与审核队列按稳定 ID 原位协调，手动刷新、后台刷新和写入后刷新都保留已载入窗口。
- 检查器请求按工作区与请求代次验收；无变化的静默轮询不重载详情，瞬时失败进入合并重试。

## 验收矩阵

### 自动化

- Web 静态资源契约测试覆盖新增界面 ID、正式审核路由和关键交互函数；
- JavaScript 语法、lint 与 Git whitespace 检查通过；
- Remote 定向测试和 Mac Debug 构建需通过后方可完成运行验收；
- 自动化测试不读取 `/Volumes/HDD2` 受保护真实数据。

### 已登录桌面浏览器

1. 在照片模式筛选“猫”，载入至少两页，等待轮询或触发刷新；结果数、滚动位置和筛选保持。
2. 切换视频再返回照片；原来源、筛选、选择和滚动位置恢复。
3. 调整九档密度，隐藏再显示侧栏和检查器；刷新页面后非敏感布局偏好保留。
4. 验证普通点击、Command 点击、Shift 点击、Command-A 和空白框选。
5. 用方向键与 Page Down 移动，Space 预览；关闭预览后列表位置不跳顶。
6. 多选至少两张照片，确认标签聚合状态与各照片真实决定一致，再执行一项批量更新。
7. 审核页分别执行 P、X、U；U 后项目只出现一次且原标签决定不变。
8. 让 Host 产生标签、资产和任务事件；只有对应区域更新，已载入图片不灰屏重载。

### 390px 窄屏

- 来源和模式切换可触控使用；
- 检查器覆盖层可打开、前后导航并关闭；
- 多选工具栏、命令面板和审核操作不横向溢出；
- 登录、退出、轮询和预览错误状态均可恢复。
