# ADR-095 自动可编辑创作闭环

2026-09-23，已实施并通过合成素材真实模型闭环验收。

此前 ADR-086/093 的实现只发布 Agent 协作请求，按钮却暗示自动生成。用户明确要求补齐自动方案、应用、人工微调、真实渲染进度和成片。本阶段增加 editable-story-v1 自动模型执行；自由场景仍需外部 Agent，不冒充已自动化。

在现有 OpenMontage 守护进程中串行接收创作任务，以独立子进程调用 App 配置的兼容模型，保持执行器心跳。协议 1.2 请求增加逐次模型授权（精确 endpoint/model）；照片范围由已冻结故事包和哈希约束。App 在发送前明示意图、事实、已选派生照片、接口与模型、单次调用及可能费用，默认未授权。未授权、配置不一致、素材改变、取消均不发送。旧 1.0/1.1 协作请求不自动消费。

模型只返回数据方案，不运行模型生成代码；保留全部照片顺序、章节及锁定/人工修改的字幕时长。最小主路径允许生成标题、逐镜字幕、时长和创作说明，章节结构保留供用户手工调整。目标时长受镜头数量与锁定限制，冲突在说明中呈现。派生照片缩至最长边 768 用于理解，不外发原图或配乐。一次请求最多一次模型调用，不自动重试，崩溃恢复报告中断，避免重复计费。

方案通过现有严格约束验证后原子返回；App 自动读取状态与方案，用户应用后可使用现有编辑器改字幕/时长、撤销、保存，再由用户启动冻结渲染。渲染沿用真实 OpenMontage 状态与媒体校验。创作使用阶段消息，不伪造百分比。异步模型调用不影响执行器心跳；取消优先于应用。

验收以合成素材进行。外部真实模型调用须有本次授权；loopback 模型只证明协议/流程，不能记为真实模型创作质量通过。日常 App 备份、构建、更新与现场验收后记录结果。

验收记录：[`AUTOMATIC-STORY-ACCEPTANCE-20260923.md`](AUTOMATIC-STORY-ACCEPTANCE-20260923.md)。日常 App 已更新，真实模型单次返回、方案应用、人工字幕修改、OpenMontage 渲染、重开恢复结果和打开播放均已验证。
