# ADR-103：Mac 与 iPhone 协同照片导入

日期：2026-10-08。状态：已实现；真实选择性导入人工验收待完成。承接 ADR-102；不改变 Photos 写入、来源清理、双端身份或已批准 migration。

## 产品决策

所有者要求在 Mac 设置菜单识别设备、选择性导入照片，并一同保留相簿、红心和标记。所有者进一步明确：只提供 Mac 与既有 ImageAllMobile 协同的一条流程，不增加独立 USB 文件导入路径。

本 ADR 首轮 USB 设备发现仅为连接提示。所有者随后授权补齐真实 USB 传输，见 ADR-104；仍不打开 PTP 照片会话、不读取其媒体、不把 USB 名称与 Host 设备身份自动关联。照片与整理事实均来自 iPhone 上的 PhotoKit 和 ImageAll 本地库，经已有配对/选择范围/归档校验链路导入。USB 信任不能代替 Photos 权限或 ImageAll Host 配对。无需另建手机 App。

当前主线已有 PhotoKit 授权、手动分享范围、来源相簿成员/目录、来源红心、ImageAll 标签和集合快照，以及 Mac VerifiedPhoneArchiveImporter。本轮补齐设备发现、统一设置入口、手机一键“同步所选目录与事实 → 传输同批原件与快照”，复用已验证身份和归档格式。

## 用户动作到结果

1. Mac 设置“设备与导入”显示 USB 连接设备，提供权限、选片、配对和接收目录指引。既有“移动 Host”配置迁入同一页，不保留第二个导入入口。
2. iPhone 在“此 iPhone”授予权限并选择照片加入“待分享”。有限权限可导入获准媒体，但来源相簿覆盖明确不可用；完整相簿需要完整访问权限。是否保存未选成员所在相簿目录/空相簿由既有默认关闭选项控制，不能扩大媒体选择。
3. iPhone “导入所选照片与信息到 Mac”先提交明确选中范围的目录/事实，再完成既有共享同步。发现冲突、待提交操作或待拉取变化时停止原件传输，并提供处理原因；不忽略冲突形成“完成”假象。
4. 无未处理共享事实后，对同一授权范围运行既有逐资源归档传输，保留 Photos 原件。源身份、范围或权限变化仍由现有校验拒绝；中断允许同批重试。
5. Mac 显示已校验接收批次，用户点“导入照片与信息”后同时校验媒体、来源相簿与红心、ImageAll 标签/集合。可在 App 查看独立副本和整理信息。独立恢复/备份/来源清理属于进一步迁移验收，收纳为可展开的高级入口，不阻塞普通导入。

## 范围和安全

- 相簿：可访问用户相簿、文件夹路径、所选成员关系；不承诺智能相簿规则或其他 App 私有组织信息。
- 红心：来源 Photos 收藏观测与 ImageAll 收藏目标保留各自语义，不能覆盖为同一未经观测值。
- 标记：ImageAll 标签和集合，不承诺读取其他 App 的私有标记。
- 选择在 iPhone 端完成；Mac 查看手机明确分享的范围并确认入库，不远程遍历整机 Photos。
- 本任务为单向媒体复制和事实导入；不在真实手机执行收藏写回、标签变更、删除或清理，不开启 iCloud 原件下载。现有归档资源请求 networkAccessAllowed=false。
- 自动化只用合成库和直接 XCTest bundle，不启动生产 Photos 测试宿主。真实手机仅只读连接发现；真实媒体导入由用户手动选择范围和接收位置后触发。

## 验证标准

Mac/iOS 当前项目构建；共享冲突与未完事实门的主路径/失败路径测试；既有相簿、红心、资源与事实同批导入回归；原生设置 UI 与 USB 发现只读验收。未执行真实照片复制时，必须把真实导入结果标为 NOT_RUN。

## 本轮验证记录（2026-10-08）

- Mac 当前 Xcode 项目 `build-for-testing` 成功；iOS 针对连接设备签名构建成功，签名校验通过，安装及启动成功，所有者确认手机 App 可以打开。
- SwiftPM 共享导入准备门和归档协议：20 项测试通过。直接 XCTest 的 `PhoneArchiveImportTests`：21 项合成测试通过，含相簿目录、有限权限覆盖、来源/目标红心、原件与事实持久化、重放和中断恢复。
- 从本轮 Mac 构建的模块加载真实 `DevicePhotoImportSettingsView`，仅创建设置页；临时 HOME、空 Host/导入容器，无生产 composition root 或 PhotoKit。原生界面显示连接 iPhone 的设备名与“USB 已连接”，布局截图已检查。此证据不代表生产 App 整体运行或真实图库验收。
- Mac/iOS 构建与验证产物位于 `/Volumes/SSD1/.codex-builds/ImageAll-DeviceImport-20261008` 和 `/Volumes/SSD1/.codex-builds/ImageAllMobile-DeviceImport-20261008`；Mac `Evidence` 保存设置页截图和测试日志。未替换日常 App，未运行生产 Photos XCTest 宿主；未读取受保护 HDD2 数据。
- **NOT_RUN：真实手机媒体传输、Mac 入库和来源信息逐项人工对账。** 需所有者在手机授权并选择具体范围、在 Mac 确认接收位置后操作；不以设备发现、签名启动或合成测试推定真实导入成功。
