# ADR-050：图库总览与保守精确去重统计

- 状态：Accepted
- 日期：2026-08-04
- 范围：macOS App 左侧「图库总览」入口
- 安全边界：只读 ImageAll 目录库；不遍历来源、不启动 PhotoKit 同步、不读取原照片

## 1. 背景

现有图库入口适合逐项浏览、审核、训练与瘦身，但缺少一个回答整体问题的页面：当前目录中有多少照片和
视频，确认去掉绝对相同副本后还剩多少，以及这些媒体如何分布在来源、时间和人工正样本标签中。

“去掉相同”如果混用视觉相似、代表帧相同或未完成指纹的项目，会把估算误写成事实，甚至让统计看起来
比真实图库更少。因此总览必须同时呈现结果与证据覆盖范围。

## 2. 决策

### 2.1 导航和交互

- 在 macOS App 左侧「图库」分区首位增加「图库总览」；不替换「全部照片」。
- 页面进入时读取一次统计，支持按钮刷新和下拉刷新。
- 刷新只执行 SQLite 聚合查询，不触发来源扫描、PhotoKit 访问、iCloud 下载、指纹补算或任何写入。

### 2.2 总量范围

总量采用与普通图库默认浏览一致的目录口径：

- 只统计 `asset.locator_state = current`；
- 排除 `availability = recycled`；
- 排除处于 `pending / recycled / restoring / purging / purged` 回收生命周期的资产；
- 排除 PhotoKit 完整对账或删除变化已经确认不可见的 Apple Photos `missing` 资产；其目录行暂留，若相同
  PhotoKit 标识重新出现可恢复原有 ImageAll 身份、标签与红心；
- 文件夹来源继续保留 `available / missing / unreadable / unsupported` 并单独展示可用状态分布，便于定位
  离线卷或路径问题。

因此页面表达的是 ImageAll 当前目录事实，不宣称是 Apple Photos 或磁盘来源的实时全量。来源尚未完成
同步时，刷新总览不会隐式同步。

### 2.3 “绝对相同”与去重后数量

只有同时满足以下条件的资产才进入精确去重证据集：

1. `asset_similarity_fingerprint.content_revision` 与资产当前修订一致；
2. `content_sha256` 非空；
3. `content_digest_origin = verifiedOriginalBytes`。

按 `media_kind + content_sha256` 分组，每组只扣除 `成员数 - 1` 个冗余副本。未完成摘要、旧摘要、视觉
派生摘要、感知相似和视频代表帧相同均不扣除，继续按独立媒体保守计数。页面必须显示照片和视频各自的
精确摘要覆盖数量，避免把低覆盖率下的“未发现冗余”误读为“没有冗余”。

### 2.4 多维统计

首个纵向切片展示：

- 照片 / 视频：原始总量、保守去重后数量、确认冗余、精确摘要覆盖；
- 来源：每个来源的照片 / 视频构成；
- 正样本标签：活跃标签中人工 `accepted` 的照片 / 视频数，及至少拥有一个正样本标签的媒体数；
- 时间：优先拍摄时间、回退修改时间的年度分布，并单列无日期媒体；
- 可用状态：可读取、缺失、不可读取和格式不支持。

正样本标签允许同一媒体出现在多个标签中，因此标签柱状图之和不等于图库总量。

## 3. 实现边界

- 聚合在一个 GRDB `read` 快照中完成，UI 不直接访问数据库。
- 不新增 migration，不持久化统计缓存；当前规模先按需查询，避免产生陈旧派生事实。
- 来源图表首屏最多显示媒体数最多的 8 个来源；标签显示正样本最多的 12 个活跃标签；时间图显示最近
  16 个有记录的年份。总量 KPI 始终来自完整聚合，不受图表截断影响。
- 本切片只进入 macOS 原生 App；Remote / Web / iOS Companion 是否需要同等总览另行决策。

## 4. 验收标准

1. 侧栏可进入「图库总览」，且不会短暂显示上一页照片网格。
2. 合成目录中跨来源的两个已验证同字节照片只产生 1 个确认冗余；视觉派生相同的视频不被扣除。
3. 历史资产和回收资产不进入总量；缺失资产进入总量并出现在状态分布。
4. 来源、正样本标签、年份、无日期和照片 / 视频拆分与合成 fixture 一致。
5. 聚焦测试使用临时 SQLite，构建和测试不启动生产 App 宿主，不访问受保护真实图库。

## 5. 后续

推荐下一纵向切片是“总览下钻”：点击来源、正样本标签、年份或可用状态后，进入现有图库并带入等价筛选；
验收必须证明筛选口径与总览数字一致、最后一次导航胜出，且返回总览时保持滚动位置和已加载快照。

若总览在百万级目录上的实测延迟不可接受，再增加由目录事务增量维护的统计事实表；在有基准证据前不
提前引入缓存失效协议。视频“绝对相同”只有在未来取得经验证的完整视频字节摘要后才能提高覆盖，代表帧
摘要仍不得升级为绝对相同证据。
