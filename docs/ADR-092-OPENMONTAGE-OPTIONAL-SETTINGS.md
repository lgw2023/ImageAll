# ADR-092 — OpenMontage 独立配置与可停用集成

状态：已实施，2026-09-22。

## 事实与范围

源码的 `config_model.py` 定义模型、预算、检查点、输出和工作子目录，但本地任务执行器没有通用的 LLM 编排循环。创作方案由外部 Agent 提供；固定模板与当前编排不需要模型 API Key。不得用配置表单暗示已有自动多模态创作。

本轮集中管理既有配置契约与工具读取的服务环境变量，不新增远程模型调用或素材上传。单次制作的模型、声音、提示词等专用输入继续属于任务。服务可用性仍取决于其账号与依赖；保存凭据不是一次 API 调用的成功证明。

## 决定

- App 设置使用独立 OpenMontage 标签，分为运行、模型与服务、制作默认值。模型信息提供结构化表单，全部上游全局配置可校验后保存；可选服务按类别配置。已知工具环境变量使用白名单，不能借表单注入 PATH/PYTHONPATH 等进程控制变量。
- 服务配置（包括密钥与端点）统一保存在设备本地 Keychain 的独立 item。主 App 与同团队签名的 helper 仅共享该访问组；不通过 URL、命令行、任务包或临时 JSON 传递密钥。helper 启动时从钥匙串加载，经过白名单校验后传给自己的执行器进程。关闭“向执行器提供服务配置”时不加载服务凭据。
- 非敏感全局配置存入 UserDefaults；每次实际启动冻结为任务目录 configurations 下的独立 JSON。通过 OPENMONTAGE_CONFIG_PATH 与源码的小型显式补丁让上游配置加载器读取此快照。配置和凭据不热替换正在运行的执行器，需完成当前任务后停止并重启。
- 默认保持已有集成启用。关闭集成立即拦截 App 新请求，并发布 finish-current 停止请求；不取消当前任务或删除作品。断开目录同时停用并清除目录 bookmark，原目录和作品保留。清除凭据是单独操作；已有进程中的凭据在进程退出时释放。
- 原生编辑、预览和导出没有依赖此开关。模板入口停用后不可用；发布、状态和启动的底层目录解析也设门禁，避免仅在界面禁用而后台仍可请求。
- 模型、预算、检查点属于创作流程配置，不承诺所有工具都强制执行预算上限；故事明确参数优先于输出默认值。说明直接呈现在设置页。

## 验收

聚焦验证配置保存/校验、非法进程环境字段拒绝、停用门禁；签名 helper 与 App 的 Keychain 共享使用合成凭据验证，不访问付费服务。UI 检查设置独立入口、保存、启动、停止、停用与重新启用，恢复原配置与日常 App。

2026-09-22 验收：Debug 构建与聚焦 XCTest 通过；日常 App 中使用隔离任务目录和无效合成 Key 完成保存、启动、已连接、断开、停用、重新启用。helper 报告读取 1 个配置字段；任务目录全文检查未包含合成 Key，heartbeat 最终为 stopped。已清除测试凭据并恢复原任务目录。无真实 API 请求。

helper 使用宿主 App 的 application-identifier、同一 provisioning profile 和专用钥匙串访问组，Bundle identifier 保持独立。最初仅添加共享 entitlement 会被系统拒绝，实际启动验收后改为随组件嵌入宿主 profile；签名校验和 Launch Services 启动通过。
