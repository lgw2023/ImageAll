# ADR-109：USB P0 浏览收口与缩略图驻留预算

2026-10-20，已实施并经用户实机验收通过。依据 USB-IMPORT-NEXT-PHASE 的 P0；不改变传输、归档、数据库格式或手机数据。

> 2026-10-23：侧栏设备分享入口及五秒在线轮询要求已由 [ADR-114](ADR-114-IPHONE-SOURCE-ONLY-NAVIGATION.md) 取代；以下保留历史决策与验收记录。

## 实时差异

接管时原进程的 1 GiB 保护已于 11:24 左右触发，物理峰值 1,077,332,080 字节。
Xcode 停在 SIGTERM，后台派生图任务处于图片整文件读取；随后进程退出。保护触发前夜间
约十小时保持约 451 MiB。没有足够现场证据确定本次峰值的唯一归属，不能继续引用此前
“保护正常”的快照，也不能把读取栈直接当作泄漏证明。

代码审计确认图库的编码缩略图缓存只限 3,000 项，没有字节预算；实际持久缓存中网格图
可达到约 654 KiB。解码准入预算与 decoded NSImage 缓存均不能限制这份长期保留的 Data。

## 决定

- 编码缩略图缓存同时执行 3,000 项和 64 MiB 上限，按已有 LRU 淘汰；替换、清空与淘汰
  同步维护字节计数。单项超过预算不保留，同时移除同身份的旧值，其他缓存继续可用。
  只改变可重建内存缓存，不删磁盘缓存或原件；缓存未命中继续原有加载链路。
- 本地来源显示“设备名 · 已导入 Mac”，设备分享入口放在“设备 · 分享目录”，行名标明
  “分享快照”。在线只表示该设备当前有已认证且 ready 的事件连接；连接关闭或 Host 停止
  即移除，侧栏每五秒查询一次内存状态。不依据 lastSeen 或快照推断在线，也不发起连接。
- 来源和相簿行增加稳定 accessibilityIdentifier；不改变选择、层级和原件只读授权。
- 先验证合成 2,889 项字节预算、LRU/替换/超预算失败路径，以及既有原生来源/视频主路径。
  合成保护 512 MiB，真实 UI 保护仍为 1 GiB。缓存修复通过不等于本次实机峰值已归因。

## 验收边界

证据目录：`/Volumes/SSD1/.codex-builds/USB-P0-20261020/Evidence`。
真实目录不遍历；正式数据库仅 `mode=ro` 对账。当前 2,866 项、47 相簿、1,874 成员、805 红心
及发布凭据实时核对通过。23 项不处理，原接收暂存不重建，不重传、不清理手机、不改变网络。
视频实际播放进度、相簿导航及新版本运行证据须单独记录；P0 通过之前不进入 P1 格式改造。

用户补充触发时可能正在预热缩略图。代码确认整来源方形预热逐项调用 rememberThumbnailData，
与前台共用上述缓存；本次字节预算同时覆盖该路径。此线索加强了排查方向，仍不等于完整归因。
