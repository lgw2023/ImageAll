# ADR-098 制作流程进入右侧分层检查器

2026-09-23。

制作设置原为固定 640×650 sheet，遮挡预览且将状态轮询绑定到弹窗生命周期。改为右侧“镜头 / 创作 / 制作 / 信息”模块；“制作”内分设置、方案、进度与成片三级业务页面。工具栏和创作页入口切换同一个检查器。模型外发确认作为设置页内联卡片，保留接口、模型、照片范围、计费提示与逐次同意；系统文件保存/目录授权继续用原生面板。

创作发布/后台模型处理显示不定量线性滚动条和执行器阶段文字，不编造百分比。请求轮询随故事编辑器存活，不因切到镜头或创作模块而停止。开始处理自动转到进度页；收到并校验方案后转到方案页。应用后回到镜头编辑，成片进度页提供真实执行器百分比和打开/另存成片入口。底部仍保留紧凑创作进度及取消入口。

编辑保护：发布/创作处理、成片提交/执行、导出期间限制镜头加入/移除/排序/替换、字幕/时长、标题/章节、意图/目标、模板/音乐与撤销重做。View 禁用与模型方法 guard 同时实施，防止键盘和拖拽绕过。分页导航、预览、状态查看、取消继续可用，移除整个编辑器的 blanket disabled。方案返回、失败或取消后恢复编辑；应用方案仍执行既有指纹校验。素材准备中的取消会取消发布 Task，在写出可执行请求前检查 Task cancellation。

本次不重新调用付费模型、不读取真实照片。使用既有合成验收环境和用户此前授权的 macOS 辅助功能脚本检查分页，合成 pending/cancel 协议测试验证编辑锁定及恢复。

验收记录：Debug 构建通过。3 项定向回归全部通过（后台 pending 时阻止字幕/时长/意图/排序/移除/保护/撤销写入，取消恢复编辑；自动方案应用；素材缩略图及批量编辑回归）。使用隔离合成故事现场打开右侧制作页，切换设置、方案、进度与成片，AX 树无制作 sheet，截图确认预览无遮挡。未提交真实模型或渲染任务，本轮不声称重新验证真实渲染百分比来源；沿用已有执行器快照进度。合成环境的任务目录未授权，因此未启动服务，其连接错误状态也保持可见。
