# ADR-105：iPhone 待分享主任务与选片管理分离

- 状态：Accepted（按 2026-10-09 用户指定范围实施）
- 范围：当前 Xcode iOS 项目的原生 SwiftUI“此 iPhone → 待分享”
- 关联：[ADR-103](ADR-103-DEVICE-PHOTO-IMPORT.md)、[ADR-104](ADR-104-USB-PHONE-IMPORT.md)

## 问题与范围

原 `LocalShareScopeView` 在主导入按钮之前铺开全部选择，数千项时主操作与错误不可见；整理信息、离线归档与来源清理混在一页。用户确认整批传输仍会中途停止，明确暂缓 USB、超时、传输性能与底层根因排查。本决策只整理页面及其必要的交互生命周期，不宣称传输可靠性已解决。

## 页面与主路径

首页保持“待分享”入口，标题简化为“待分享”。按已选摘要（照片／视频数量）、目标 Mac／通道／连接、当前任务、相簿目录选项组织。`safeAreaInset` 固定主操作，避开底部 Tab Bar；首页不生成资产行。长错误先显示两行原因，完整信息按需展开。

点击摘要进入独立选片管理弹层：懒加载列表、小缩略图、日期、单项预览、全选与批量移出。移出只调用既有分享范围 API，不删除 Photos 原件，不清除 Mac 批次。照片预览为禁止网络访问的 PhotoKit 派生图；视频只预览封面。本轮不实现原件播放或云下载。批量更改逐项执行既有存储事务，结束后仅刷新一次；失败如实报告部分完成，不承诺整批原子更改。

连接详情放入弹层，复用 `USBPhoneConnectionSection` 与原身份确认。网络配对仍在“Mac 图库”。不新增或自动切换通道。运行时可以查看选择与连接，但禁止更改范围、配对和导入选项。

“更多操作”：仅同步目录与整理信息、冲突与身份核对、离线包生成／选择／续传上传、整理信息快照、共享集合改名。

“高级迁移”：逐资源来源检查点、归档验收检查点、Mac 清理请求、只读来源与副本核验、清理记录、来源退役及其原有确认门。只是调整入口，不授权工具执行任何真实清理。

## 状态与操作

| 可观察状态 | 显示与下一步 | 固定主操作 |
|---|---|---|
| 无选择 | 当前 0 项；先明确加入范围 | 选择照片与视频 |
| 未授权 | 保留已有选择，恢复访问 | 处理照片权限 |
| 有限权限 | 仅可访问媒体；相簿不可读取 | 目录选项关闭时仍可导入；开启则处理权限或关闭选项 |
| 未连接 | 目标 Mac、USB／网络、未连接 | 连接目标 Mac |
| 待确认 | 核对实际 Mac ID 与证书 | 核对 Mac 身份 |
| 准备／复验／封存 | 实际阶段；不显示传输速率或虚构百分比 | 暂停导入 |
| 原件传输 | 本次项目数、真实 ACK 字节、已有传输均速 | 暂停导入 |
| 正在暂停 | 等待当前任务结束；不开放新任务 | 禁用“正在暂停” |
| 已暂停 | 保留本次数量、目标；不因重连自动启动 | 恢复原连接后继续原批次 |
| 失败 | 失败阶段与原因、旧进度保留 | 恢复条件后重试原批次 |
| 范围／选项改变 | 不能把新范围称为原批次续传 | 到选片页显式恢复本次范围与选项 |
| Mac 身份／证书改变 | 不能把其他 Mac 称为原目标 | 恢复原 Mac 连接 |
| Mac 已接收待入库 | 接收回执与资源数；不能查询 Mac 入库完成 | 查看 Mac 入库步骤 |
| 辅助操作执行中 | 操作页显示原有进度与结果，主路径互斥 | 主按钮禁用并说明等待 |

成功后仍须在 Mac“设备与导入”入库、打开副本核对。下一次独立导入需从更多操作显式选择，不自动启动。

## 生命周期与保留边界

审计发现原页面在 `onDisappear` 和 scenePhase 非 active 时取消 `streamTask`。新增子页若直接 push，会触发主页面离开；因此本轮采用主页面持有任务、独立 sheet 内导航，打开选片／连接／更多入口不主动取消任务。实际离开主页面或进入 background 仍请求暂停；系统短暂 inactive（弹窗、身份确认等）不直接取消。这里只处理明确的 UI 导航契约，不把它认定为用户中途停止的根因或后台可靠性修复。

展示上下文放在 `LocalLibraryModel`，在本次 App 会话内返回页面后保留。相簿选项不因打开／关闭弹层重置，保存到本 App UserDefaults。用户在本轮明确要求默认开启：无已保存偏好时默认 true；之后用户明确关闭则持久保留 false。旧版选项仅为页面内存，无法从已有持久记录恢复旧值；本轮沿用用户新指定默认，不更改照片选择。有限权限时提示完整权限要求，允许用户关闭目录选项继续导入可访问媒体。展示状态不代替传输 checkpoint；App 重启后的续传仍由原归档记录和原导入方法核对，UI 不自动恢复真实传输。配对、既有选择、整理事实、回执、续传文件不重置。

## 验证门

状态判定用无宿主的 Swift 可执行检查，先验证失败，再实现暂停上下文与目标匹配。显式 `--share-ui-probe <scenario>` 复用生产 Dashboard／选片组件；不创建生产照片模型、资料库、凭据或连接，合成行 identifier 为 nil。涵盖 0／2,889 项、权限、连接、准备、传输、暂停、失败、Mac 已接收，以及导航、固定按钮、批量管理、大字体。签名设备构建与真机普通页面另行验收；安装前必须核对当次空闲授权。不得为 UI 验收恢复真实传输。

实际结果与截图记录在本轮构建目录 `ShareUI-20261009/Evidence`。整批真实传输、封存、入库、逐项对账稳定性属于独立未完成事项。

## 本轮设备可用性

用户先确认传输已停止／暂停并允许更新，后告知手机连接暂时不可用。本轮完成 Simulator 显式合成界面与签名设备构建；真机安装及原有 2,889 项真实页面核对须待设备可用，不冒充已执行。

## 后续生命周期调整：长批次鲁棒性

2026-10-09 用户要求减少传输限制、提高稳定性。ADR-104 的恢复改造将主导入 Task 从页面 State 移到 LocalLibraryModel；主页面离开不再取消主导入，返回后仍可通过同一 Task 暂停。App 进入后台仍由根视图请求暂停，辅助高级核验/清理操作仍沿用原页面离开取消规则。活动主导入临时阻止自动锁屏，结束恢复系统原状态。此条取代前文“实际离开主页面请求暂停”对主导入的规定，不扩大后台、云下载或真实照片写入授权。
