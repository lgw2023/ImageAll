# ADR-118：新任务完成后的受控自动收尾

日期：2026-10-26。状态：已实现，独立 USB 实机验收通过。

按 ADR-116/117 已验证的收尾能力，新增手机任务作为双端收尾驱动者。新手机任务才登记自动收尾状态；Mac 新接收账本才登记自动收尾版本。旧任务、旧接收目录不自动接管，不扫描猜测。普通可浏览状态仅触发请求，不能作为字节完整性证明。

手机在前台、同一配对连接有效、Mac 可浏览时，先持久保存本次尝试及新随机值，然后发送显式 POST 自动收尾请求。Mac 核对配对来源和新任务登记，经接收 actor 的同步临界区暂停自身共享租约，再调用现有排他收尾。外部读者/接收器、未完成请求或路径变化导致延期。临界区无 await，新接收操作排队；退出时恢复共享租约，恢复失败则后续入口须重新取得租约才能读写。清理不写发布数据库。

Mac 暂存完成后重新完整核验最终副本，签发绑定本次任务与随机值的回执。手机再次核对连接身份和前台状态，再释放导出载荷。手机持久保存完成状态；完成后常规状态刷新不再请求回执或全量读原件。中断发生在任意一步都可重试，但新进程必须产生新随机值并重新获取回执。

忙碌、断连、进入后台或其他失败独立于导入结果：图库保持可浏览，清理显示延期原因。失败后 30 秒起退避，最长 5 分钟；重启保留已保存的退避期限，未完成尝试转为延期。下一次前台轮询/重连且期限到达时再试。无 iOS 后台保活承诺，不新增后台扫描器或通用任务系统。显式重试保留。开始下一次导入前，将当前新任务的收尾记录保存在精确登记队列中；只遍历该索引中的任务，按原主机与证书绑定续办，完成后移出待办索引但保留完成记录。队列最多 64 个未完任务，损坏或超限时明确报错，不能静默丢失记录。

验收先证明失败不改已发布来源、资源及必要记录，再用新独立 USB 合成任务验证活跃读者延期、断连/进程重启后新回执继续、双端完成后同任务零新增上传。保留最终全量校验、512 MiB 合成保护和 1 GiB 日常保护。

## 验收（2026-10-26）

新增状态机、接收租约交接及延期队列均先 RED 后 GREEN。协议/回归 36 项有效测试通过（另 2 项独立进程专用测试本轮跳过，既有进程中断证据见 ADR-116/117）。独立真实目录库测试证明活跃读者、只读载荷导致收尾失败时，发布与最终副本、必要账本/清单保持；恢复权限后新回执完成释放。手机任务持久化与开始下一任务时保留延期登记的直接 XCTest 通过。

新 1 项/16 MiB 独立 USB 任务：忙碌延期后主动关闭 USB 隧道，手机离线重启；Mac 重启后重连，以新随机值取得新回执并自动完成双端收尾。同任务随后双端重启及最终手机安装包再次复测，新增上传 0、清理请求 0、常规全量原件读取 0。手机读回保留 manifest、stream record、retirement intent 和零字节资源占位。此轮断连由关闭真实 USB 隧道触发，没有声称再次实体拔线；本轮不重测 4 GiB 性能。
