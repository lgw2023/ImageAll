# ADR-073：待审核建议的卡片操作与连续审核

- 状态：已接受（项目所有者于 2026-09-09 要求全部实施）
- 范围：Mac 原生审核、新版 Web 审核；Web 仅在独立开发 worktree 交付。

## 决策

1. 标签卡片的整个摘要区（含空白）作为一个可键盘激活的展开按钮；展开后点击摘要收起。
   生成、更新、暂停、继续、取消及审核按钮直接可见，独立处理点击，不触发卡片折叠。
   只有门槛编辑保留一层展开，不把任务按钮再藏入 disclosure。分组标题整行可点击。
2. 总览提供标签搜索、仅有待审筛选和生成中心显隐；筛选不修改持久化分组、标签顺序或折叠偏好。
3. 审核固定操作栏显示所选照片数、属于、不属于、跳过和最近一次撤销。提交期间统一阻止重复命令。
   成功反馈区分确认和拒绝，数量采用唯一照片数；原始建议条数与已载入照片数分别标注。
4. 默认按照片呈现，同一照片在当前标签下的已载入多模型建议合并，模型与原始分数可展开查看。
   提供按模型逐条查看。保留服务端 origin 分页和顺序，不将不同轨道分数直接比较；后续页的相同照片
   合并到现有卡片。汇总只描述已载入窗口，不能伪称全库唯一照片数。
5. U 命名为“跳过”：不写标签决定、不改变排序、不建立稍后集合；末尾优先续载，确认没有下一页后
   才回到已载入队列开头。批量操作结束后若仍有游标，继续加载而非误报完成。
6. 撤销保留当前分页窗口，以权威待审结果验证被恢复项目后原位补回，恢复原主选择和可见锚点。
   不重新安装第一页 UI；已更新或失效的建议不从旧快照伪造回来。一次撤销契约不扩展为历史系统。
7. 加载中、首屏失败、分页失败、来源未选、样本不足、生成中、无结果和审核完成分别呈现；失败
   保留可用内容并提供重试。空状态提供返回总览/调整范围等直接入口。
8. Web 上下键按当前网格列数导航，按钮和快捷键共享提交门禁；卡片内部输入与按钮保持独立焦点。

本决策替代阶段 3 中“门槛与生成共同折叠”、按来源重复呈现及 U 的旧帮助文案。原始分数展示仍遵循
SUGGESTION-THRESHOLD-SPEC；真实照片、数据库原子性和云端预览授权边界保持有效。

## 验证

- 合成队列覆盖重复模型合并、跨页跳过、批量决定、原位撤销、读取失败恢复和重复提交门禁。
- Web 桌面/移动交互验证整块卡片展开、内部按钮不折叠、筛选与模型中心显隐、连续审核。
- Mac 隔离构建及直接 test bundle；不启动生产 composition root、不读取真实照片。
