# ADR-079 待审核建议的视觉层级

状态：Accepted，2026-09-17。

用户反馈现有界面简陋：多模型按钮重复堆叠、文案截断、卡片高度不一。采用原生 macOS 卡片工作区，保留分组折叠与滚动边界修复，统一卡片信息区高度、增加标题层级与留白。样本数量使用带文字的中性统计；生成方式归入单个菜单，审核为主要操作，门槛按需展开。无待审时不制造待审计数。保持现有生成资格、确认弹窗、队列及后端语义。

用户要求默认更新日常 App 并在其中验收；隔离环境仅用于任务必要情况。该约定已写入 AGENTS.md，不扩大照片写入或云下载权限。

验收：Debug 构建、日常 App 的卡片布局、模型菜单与门槛展开、窄窗口及滚动检查。不得为了界面验收启动生成扫描或修改照片。

## 2026-09-17 用户修订：直接操作优先

用户明确要求移除常驻样本状态、确认/拒绝统计和补样本说明；取消单标签生成菜单。卡片直接展示特征、个人、超级个人三个按钮，保留完整名称，使用纵向等宽排列避免截断。各按钮独立判断能力，不可用时禁用并在外层悬浮区域说明原因，个人模型不可套用特征模型的正反样本门槛。门槛与审核仍可直接访问；现有来源确认流程不变。本修订取代上文的生成菜单和常驻样本概况决策。

修订验收：Debug 构建、签名与 diff 检查通过，已替换日常 App。真实截图确认卡片无常驻样本小字，三个等宽按钮直接显示且名称完整；AX 核对缺拒绝样本时特征禁用而个人按钮仍可用、缺确认样本时个人按钮禁用，均附对应 Help。禁用按钮外层保留悬浮区域，未通过自动化实际移动鼠标验证气泡时序。点击“独库公路：生成超级个人建议”直接打开原有来源确认弹窗，随后取消，没有启动扫描、训练或照片写入。备份与构建日志：`/tmp/ImageAll-DirectActions-20260917/`。


## 2026-09-17 用户修订：用工作方式命名建议

用户指出“个人建议 / 超级个人建议”难以理解。卡片按钮改为“按样本匹配”（质心）和“用模型识别”（AdamW 分类），对应模型统一为“样本匹配模型”和“学习识别模型”。同步训练入口、来源标记、默认门槛、确认说明和状态提示；悬浮说明解释两种工作方式。不用“超级”暗示未经验证的准确率优势。仅改展示文案，保留内部方法标识、模型文件、训练与扫描行为。

验收：Debug 构建、签名校验、diff 检查通过。已更新日常 App，并在真实待审核界面确认两种新按钮完整显示、禁用状态与 Help 原因保留、工具栏模型名同步。本轮未启动训练或生成扫描。构建日志与替换前 App 备份：`/tmp/ImageAll-Naming-20260917/`。
