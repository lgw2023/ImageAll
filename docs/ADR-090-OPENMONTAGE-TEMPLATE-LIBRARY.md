# ADR-090：积累式 OpenMontage 模板库

日期：2026-09-22。状态：设计提案，首批样式基准已冻结，尚未实施 App 功能。

## 问题与范围

用户希望将已经调整满意的两种制作风格保存下来，以后换照片直接套用。现有 `TimeStoryProject.templateVersion` 表示旧故事生成策略，并非可复用的样式资源；创作意图、可编辑协议与 Atelier 版本也没有统一的模板引用和参数快照。只添加提示词预设无法保证相同字体、转场和位置。

首批模板见 `openmontage-templates/README.md`。本轮交付总结、冻结参考与接入设计；不修改或重启日常 App。

## 产品方案

在“时光故事”的固定顶部操作栏添加“模板库”，打开工作区内的模板浏览面板，与素材库、预览、属性和时间线协同，不使用独立模态创作窗口，也不增加深层折叠。

卡片展示名称、成片预览、两句效果说明，以及“可编辑创作 / 自由场景”标签。“套用到当前故事”在同一工作区给出参数和变更预览。常用参数只显示文字内容、文字时长或位置、配乐；工程参数进入详情页。模板决定适用制作路径，用户无需再次猜选三种制作方式。

套用过程：选照片和时长 → 选模板 → 校对新文案 → 预览 → 制作。模板不自动提交渲染，不自动重新选片。库中预览示例与当前项目预览明确区分。

完成一轮修改后，可“另存为模板”：输入名称，保存样式参数及预览引用，去掉本次照片、资产标识、正文和源文件路径，保留可替换字段。修改现有模板产生新版本，旧项目固定旧版本。

## 数据与执行契约

- App 负责模板目录、预览、选用参数、版本记录与保存；OpenMontage 负责模板实现及渲染。模板的可用性依据实际制作端能力查询，不能仅凭本地卡片存在。
- 模板描述包含稳定 ID、语义版本、显示名称、制作方式、参数 schema、默认值、所需能力、实现摘要与字体许可信息。项目记录独立的可选 `styleTemplate` 引用及参数快照，兼容旧故事，不复用旧 `templateVersion` 字段。
- 发布请求绑定模板 ID、版本、实现摘要、参数快照和本次素材快照；结果回传同样绑定信息。旧请求走旧协议，新增能力需要显式协商，不能把自定义参数偷偷塞入旧字段。
- 普通模板记录只包含数据，不能从模板目录导入任意 TSX 并执行。首批渲染实现随可信本地制作端提供；个人变体使用相同实现和受校验参数。
- 模板的照片数量可变；现有 1–100 张是交换能力上限，必须显示为制作端限制，不是 18/35 张的风格限制。
- 保留照片选择、手动顺序、镜头时长与明确编辑。必要文字卡以新版本展示；锁定冲突阻止应用并指出字段。失败保留原草稿，支持撤销。
- 字幕位置用 contain 实际矩形计算：比例取 `min(容器宽/图片宽, 容器高/图片高)`，再计算居中的实际尺寸和运动变换。字幕不能溢出照片。横图、方图、小图均适配。
- 运动进度由当前镜头实际帧数计算；短镜头、短诗句的渐入渐出必须缩短以避免边界交叉。模板不固定文案数量、镜头索引和总时长。
- 模板声明样式默认值，不能悄悄切换用户已确认的 9:16；首批仅验证 9:16，其他画幅不宣称可用。

## 最小实施顺序

1. 制作端先提供两种参数化实现与能力声明，使用合成横图/竖图和不同镜头时长验证，消除当前源码中的固定尺寸、45 帧和镜头索引。
2. App 新增模板目录与项目参数快照，将两个模板贯穿“套用 → 预览 → 发布 → 校验结果”的完整路径；保留已有无模板制作路径。
3. 在同一目录支持“另存为模板”和不可变版本，形成用户积累闭环。暂不做云市场、在线分享、任意脚本安装或复杂标签系统。
4. 构建通过并备份旧 App 后更新日常 App，完成真实 UI 验收。实现与独立视频修订分别记录，不能用现有成片冒充 App 模板套用验证。

## 验收标准

- 两个模板卡片可预览与套用；不需多层折叠，制作路径自动匹配。
- 新故事使用不同照片数量、尺寸和时长，仍保留手动顺序和锁定字段。02 短卡按整数帧正确淡出；03 字幕在照片内、柔边清晰、总长不因字幕增加。
- 保存、关闭、重开后模板 ID、版本和参数一致；另存变体不改变旧模板与旧成片。
- 能力不支持、字体缺失、版本摘要不匹配给出可操作错误，禁止静默替换字体或退化为普通渲染。
- 一条合成端到端主路径覆盖模板发布及结果关联；必要失败路径覆盖版本不匹配与锁定冲突，相关旧协议回归通过。
- 本地范围和素材安全规则不变，不读取受保护照片目录，不将私人照片或项目正文写入可分发模板。
