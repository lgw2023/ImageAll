# ADR-102 实施状态

> 2026-09-24；ADR-102 仍为待评审提案。本记录只描述已经落地和验证的部分，不代表阶段验收通过。

## 当前切片

- iPhone App 新增“此 iPhone”入口，未配对 Mac 时仍可进入。本机照片授权在用户点按后请求，有限权限只展示获准资产；权限缩小时隐藏目录投影，不删除本地整理事实。当前两端各自维护本地图库，不使用 iCloud。
- PhotoKit 仅取本机用户图库资产的目录信息和按需缩略图；缩略图请求设置 `isNetworkAccessAllowed = false`。用户明确点按收藏按钮后可写回本机 Photos，写前保存目标、写后回读，失败保留待处理状态并允许重试；没有自动原件传输、媒体迁移或来源删除流程。
- 用户现在可在手机“待分享范围”单独点按生成本机原件归档。导出只覆盖已明确选择且当前仍可访问的资产；权限收缩时拒绝缩小范围静默导出。PhotoKit 逐资源写入 App 自有目录，网络访问关闭，保留每个原始/修改/配对/调整资源的结果；缺失必需资源时归档校验仍可完成，但明确报告该资产未完整。归档目录排除系统备份并设置文件保护，用户可主动打开系统分享界面选目标。系统分享的实际目录交付、Mac 入库和迁移完成回执尚未在设备上验证；该按钮不会自动发送或删除原件。
- App 自有 SQLite 保存安装身份、来源 epoch、稳定媒体 ID、标签决定、ImageAll 集合成员、收藏目标和来源写回状态。人工事实与本地审计 outbox 同事务写入；仅已显式分享资产进入 `shared_outbox`，共享资产的标签、集合和收藏目标变化与该记录同事务提交，使用稳定操作 ID 和序号。撤出分享会取消该资产的共享意图，不删除本地事实或审计历史；全量 outbox 不会发送到 Mac。用户可逐项加入或撤出“待分享”范围，并手动提交当前获准访问的目录和标签决定。范围默认空；权限收缩保留选择，提交时携带完整选中 ID 集合以区别显式撤销与临时不可见。Mac 回执指出首次导入的资产，手机持久确认快照范围、吸收该快照所含的旧整理意图，再把其后标签、ImageAll 集合成员及收藏目标操作按各自字段版本和稳定操作 ID 提交；成功 ACK 推进本地版本。手机界面会显示同标签字段版本冲突的本机决定和已知 Mac 决定；用户明确选择采用 Mac，或保留当前本机决定并生成新的操作 ID/序号在下次同步重试。标签/集合身份和同名不同 ID 的冲突仍保留待对账，不能直接覆盖；集合成员版本冲突也由用户明确选择采用 Mac 或以新操作保留本机状态。Mac 可修改已分享资产的 ImageAll 集合成员和共享收藏目标，手机手动同步拉取并应用；收藏目标只改变 ImageAll 本地目标与来源写回状态，不自动操作 Photos。新建/重命名集合尚未实现。单次目录提交当前限制为 200 KiB，超限会报错；大范围分页尚未实现。
- Mac 新增配对设备专用的本机目录快照接收路由和持久投影，绑定 Host、设备、安装和来源 epoch，拒绝迟到序号及来源身份变化。已共享资产暂时不可见时保留旧投影及最后可见的快照序号；只有从选中范围明确撤出才移除。原生 Bearer 请求可写入，浏览器 Cookie 写请求仍需同源验证。首次进入投影的资产会在快照回执中列出，包含先前已选中但因权限暂不可见、后来才进入投影的资产。针对已分享手机资产的标签决定、ImageAll 集合成员及收藏目标，Mac 分别保存版本化共享事实与稳定操作回执：同字段按 base revision 判冲突，同操作 ID/负载重试返回原结果，迟到设备序号被拒绝，后来的手机目录快照不能覆盖已接纳决定；权限暂时不可见时拒绝新手机操作。Mac 可在手机目录界面修改**已有**共享标签决定，按期望版本写入同一持久账本及按设备过滤的变化页；iPhone 手动同步拉取后，事务性应用变化与 cursor，同字段本地待提交意图保留为冲突。Mac 还可按成员期望版本修改已由手机引入的集合，并写入独立变化页；手机按持久 cursor 原子应用，同成员离线意图保留为冲突。Mac 也可按字段期望版本修改共享收藏目标，手机按独立 cursor 更新本地目标与来源写回状态，同字段离线意图保留为冲突。此账本目前仍以单手机来源为范围，不是完整工作区标签提交中心。Mac 主图库侧栏把已收到的手机目录列为独立来源，进入后可检索元数据，并看到接收时间、共享标签版本、集合成员、上次来源收藏观测、版本化共享收藏目标及暂未观测状态；Host 停止时仍可读取和修改已有标签、集合成员与共享收藏目标。远程 Host 设置页复用该视图。当前没有共享缩略图或原件，手机来源不进入 Mac 本机资产编辑、删除和清理工具栏；跨来源正式标签、集合与收藏双向收敛尚未实现。
- 远程 Companion 仍在“Mac 图库”入口。旧 P0–P8 的图库、审核、标签、任务和预览工作流已移植到当前主线；补齐当前 Remote Client 对标签管理、撤销、审核概览和图库筛选的封装，保留主线已有 DTO 与 Host 能力。事件通道断开后可重试，旧连接迟到事件会被拒绝。当前组合已通过选定的合成 Host 路由测试，S0 的 iPhone 界面端到端验收尚未通过。
