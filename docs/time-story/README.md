## 剪辑与审片

[旅行、人像与生活方式短片：剪辑标准与美学指南](旅行、人像与生活方式短片-剪辑标准与美学指南.md) 是项目所有者于 2026-09-21 提供的创作参考，适用于 ImageAll 与 OpenMontage 联合制作中的选片、分镜、精剪及审片。

本目录保留原文，未改写正文及其来源链接。导入时与用户提供的文件逐字节一致；来源文件名为 `旅行、人像与生活方式短片 剪辑标准与美学指南.md`。后续若需补充项目适用说明，应写在本页或对应创作项目中，避免将解释混入原文。

使用方式：

- 创作前阅读全文，用一句表达目标、一种主导风格、镜头功能和声音方向形成简短风格卡；再将具体选择写入 OpenMontage 原生创作产物与检查点。
- 以表达、选片、镜头关系、节奏、构图与运动、色彩与文字、声音、技术交付分别审片；反馈采用“位置—问题—影响—动作”。工程通过与用户审美认可分别记录。
- 指南中的时长、缩放和样段长度是试剪起点，不是固定参数、自动评分公式或必须凑齐的效果数量。不要据此开发一套以特效密度代替创作判断的模板。
- 静态照片无法提供真实动作过程、同期声或新的拍摄角度。画面裁切和数码运镜不能被记作真实摄影机运动；编辑联想不能被写成已经发生的事件、心理变化或旅行路线。
- 声音需要尽早设计。音乐、环境声和音效的来源及使用授权单独核对；后期声音不冒充现场录音。无声音素材时如实记录缺口，继续可独立完成的视觉工作。
- 本指南不扩大照片读取、外发、生成式修改、音乐下载或付费服务授权，也不改变原图只读约束。具体授权沿用当前任务的明确记录。

架构与工程边界参见 [完整 Atelier 创作版本的本地交付](../ADR-087-ATELIER-CREATIVE-DELIVERY.md)；若该 ADR 路径随版本调整，以仓库现行 ADR 为准。
