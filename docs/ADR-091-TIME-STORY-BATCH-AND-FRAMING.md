# ADR-091 时光故事镜头多选与画面适配

2026-09-22，接受。用户要求常用快捷键多选、批量镜头操作及照片与视频比例不一致时的裁剪／填充。

## 决策

编排区单击单选、Command 点选切换、Shift 连选、Command+Shift 追加范围；编排区获得焦点时 Command+A 全选、Escape 清空选择、Delete 从故事排除。输入框仍由系统处理文字选择和删除。素材库选择与镜头选择相互独立，切换故事清空镜头选择。

选中多镜头后属性区提供统一时长；批量菜单提供画面适配、锁定、解锁、清空字幕、移到开头／末尾和从故事排除。拖动选中组保持组内顺序。每次批量修改只发布一次项目状态，对应一个撤销步骤。锁定延续原有语义，只约束自动编排，不阻止用户明确编辑。排除只修改故事项目，不删除照片。

沿用已持久化的 presentationMode，增加 aspectFill（居中裁剪铺满）和 aspectFitBlack（完整显示黑边），旧项目 fullFrameWithBackground 保持完整显示及背景填充。当前不增加手动裁剪框或焦点位置。原 ADR-082 的永久禁止裁剪改为默认禁止、用户逐镜头明确选择后允许。中央原编排预览、缩略图及原生横屏 MP4 使用同一矩形计算。完整显示和裁剪新模式固定构图，避免运动引入新的边缘裁切。

故事包仍使用现有 contain 协议；对用户明确选择的新模式，在临时导出目录生成与目标画幅一致的衍生 JPEG，把居中裁剪或黑边合成进素材，运动比例固定为 1。此过程仅处理已授权选中素材的导出副本，不修改原照片，不需要向旧制作端添加未协商字段。外部创作模板自身特效和重新构图仍由模板定义，不能用原编排预览冒充模板最终效果。

## 验证

自动化仅用合成图片、临时数据库与独立 XCTest bundle，不启动生产 Photos 测试宿主。覆盖批量编辑一次撤销／重做、排除恢复、顺序、保存重开、旧模式兼容、时间线模式传递、横竖输出的画幅几何和导出尺寸；构建后备份并更新日常 App。运行证据另记。
