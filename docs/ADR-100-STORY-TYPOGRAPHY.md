# ADR-100 · 时光故事系统字体与制作约束

日期：2026-09-23。状态：实施。

## 决策

右侧「创作」增加故事级文字样式；使用可搜索、带中文样例的字体下拉面板，不另开制作弹窗。字体列表从 NSFontManager 读取本机已安装字体。标题/章节和字幕共享字体、常规/粗体，可分别调整标题 24–120 px、字幕 16–80 px。字号以画幅短边 1080 px 为参考；预览随画布缩放。

项目存储可选 typography，兼容旧项目解码，默认苹方、标题 64、字幕 36、常规。修改进入既有撤销与项目指纹机制；创作/提交期间沿用编辑锁。自动导演与 Atelier 请求中的创作意图包含文字样式约束；可编辑方案不拥有该字段，应用方案保持 ImageAll 的设置。自由场景 Agent 收到的是明确约束，其自由代码输出仍需审片。

原生 AVFoundation 渲染使用 NSFont；故事包 template 携带 fontFamily/titleFontSize/captionFontSize/fontWeight；固定 PhotoStory 与诗句模板显式消费它们。扩展包 schema 和 edit-decisions schema 一起更新，由 typography_patch.py 对固定版本运行时幂等应用；包 schema 摘要同步更新。runtime 内容摘要确保下次启动使用新组件。

本切片针对本机已安装字体。字体名称作为 CSS 字符串引用；缺失字形允许系统回退。不会上传、复制字体文件或联网下载字体。跨机器未安装相同字体时不保证排版相同；字体文件打包和逐字形覆盖检查不在本切片。

## 验证

- 本机字体清单：246 个家族，包含 PingFang SC、Songti SC、Kaiti SC、Hiragino Sans GB。
- 隔离宿主三项 Swift 测试通过：包导出（增加字体/字号/字重断言）、原生 MP4 渲染、自动创作应用与人工编辑。
- 实际 Remotion PhotoStory 渲染合成 1280×720、60 帧 MP4；逐帧查看标题和字幕，确认楷体及配置字号生效。
- 合成验收不读取真实照片、不调用远程模型。产物在 `/Volumes/SSD1/ImageAll-artifacts/story-fonts-20260923`。

界面验收：使用更新后的日常 App 可执行文件启动隔离合成故事，实际打开字体下拉、搜索 Kaiti、选择 Kaiti SC，右侧中文样例随之变化。最终版本另加入常用中文字体优先及中文别名搜索，构建通过。诗句模板另完成 30 帧宋体合成渲染。日常 App 已保留备份并更新，签名校验通过；原有日常进程未强行退出。
