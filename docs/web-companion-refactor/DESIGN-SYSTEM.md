# Web Companion 设计系统

## 产品气质

新 Web Companion 是“安静、克制、专业的照片工作台”，不是展示页。界面服务于长时间筛选、
查看、比较和批处理：高密度但不拥挤，优先展示照片和当前工作语境。不使用装饰性渐变、玻璃拟态、
浮夸阴影或表情符号充当核心图标。

## 设计令牌

### 色彩

| Token | Light | Dark | 用途 |
| --- | --- | --- | --- |
| `--color-canvas` | `#f4f4f2` | `#151515` | 应用背景 |
| `--color-surface` | `#ffffff` | `#1f1f1f` | 主表面 |
| `--color-surface-raised` | `#fafaf8` | `#292929` | 弹层和提升面 |
| `--color-text` | `#1d1d1f` | `#f5f5f7` | 主文本 |
| `--color-text-muted` | `#68686d` | `#a8a8ad` | 次要文本 |
| `--color-border` | `#d7d7d2` | `#3c3c3e` | 分隔和轮廓 |
| `--color-accent` | `#1769aa` | `#62a8df` | 选中、链接、主操作 |
| `--color-accent-subtle` | `#e8f2fa` | `#173247` | 选中背景 |
| `--color-success` | `#247a43` | `#66c48a` | 完成 |
| `--color-warning` | `#9a5a00` | `#f0b35a` | 警示 |
| `--color-danger` | `#b42318` | `#ff8a80` | 高风险操作/错误 |
| `--color-focus` | `#0066cc` | `#75bfff` | 焦点环 |

颜色不得是状态的唯一线索。错误、审查决定、在线状态都必须同时有文字或图标。文本对比达到
WCAG 2.1 AA，普通文本至少 4.5:1，大文本和非文本关键边界至少 3:1。

### 字体与密度

- 使用 macOS/iOS 系统字体栈：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "Segoe UI", sans-serif`。
- 数字、进度、容量使用 `font-variant-numeric: tabular-nums`。
- 层级：12 px 辅助，13 px 密集控件，14 px 正文，17 px 区域标题，22 px 页标题。移动正文不低于 16 px。
- 行高在 1.25–1.55 之间；不使用全大写长标题。

### 间距、圆角、轮廓

- 间距标尺：`2, 4, 8, 12, 16, 24, 32, 48 px`。
- 主布局沟槽 12–16 px，控件内边距至少 8×12 px。
- 圆角：紧凑控件 6 px，卡片 8 px，面板/对话框 12 px；不使用大面积胶囊容器。
- 阴影只用于表达真实层级，非必要界面用 1 px 边框代替。

## 图标

- 主图标统一使用 Lucide React，常用 16/18/20 px，`stroke-width` 保持 1.75–2。
- 纯图标按钮必须有可计算的 `aria-label`和稳定 tooltip；对不常用或高风险操作，必须显示文字。
- 品牌、媒体、地图不得为了便利用 emoji 代替。

## 布局断点

| 宽度 | 形态 |
| --- | --- |
| `>= 1280` | 三列：可折叠导航 220–260 px + 主画布 + 检视器 300–360 px |
| `900–1279` | 左导航紧凑，检视器作可叠加侧板，顶栏只保留当前流程操作 |
| `600–899` | 单列主画布，导航和检视器是模态 sheet，批处理工具固定于安全区上方 |
| `< 600` | 移动单列；筛选/详情分屏；无水平滚动；主操作不被浏览器安全区遮挡 |

规则不绑定具体设备，需同时验证 1440×960、1024×768 和 390×844。

## 交互和反馈

- 桌面鼠标密集控件可视高度不低于 32 px；所有触控命中区不小于 44×44 px。
- hover、pressed、selected、focus-visible、disabled、loading 和 destructive 必须有区别。
- 小范围成功用就地反馈；全局任务用可追踪 activity panel；错误不仅依赖 toast。
- 高风险写操作显示目标数量、作用范围、可否撤销和 Host 返回的实际结果。

## 焦点、键盘和动效

- `:focus-visible` 用 2 px 外环 + 2 px offset，不因鼠标使用而移除键盘焦点能力。
- 主区域有 skip link；弹层使用焦点圈定，关闭后返回触发元素或合理后继。
- 图库支持方向键移动、Space 选择、Enter 查看、Escape 返回；快捷键不干扰输入框。
- 常规过渡 120–180 ms，只动画 `opacity`/`transform`；不为了装饰动画长列表。
- `prefers-reduced-motion: reduce` 时取消非必要过渡、自动滚动和缩放动画；必要状态不依赖动画表达。

## 深色与高对比

- 主题模式是 `system | light | dark`，只保存模式选择，不保存业务数据。
- 深色不是简单反相：保留照片与界面的边界，减少大面积纯黑对比。
- `forced-colors` 下使用系统色，恢复按钮/输入轮廓，禁止依赖背景图或阴影表达选中。
