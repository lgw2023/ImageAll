# Web Companion 设计系统

## 产品气质

Web Companion 与 Mac App 对齐的是能力、业务语义和安全边界，不是视觉外观。Web 使用独立的
“Nocturne”语言：像现代影像档案与数字暗房，近黑舞台、强对比无衬线标题、酸性黄绿操作信号，
让照片而非窗口边框成为主角。

界面仍服务于长时间筛选、查看、比较和批处理。视觉冲击不能以牺牲信息密度、稳定点击目标、键盘
路径、对比度或性能为代价。参考现代摄影站点的 image-first、editorial/immersive 原则与 Linear
对复杂产品重新统一层级和动作位置的做法，但不复制任何具体产品的版式、商标、字体或品牌资产。

## 设计令牌

### 色彩

| Token | Nocturne | 用途 |
| --- | --- | --- |
| `--color-canvas` | `#090a0b` | 应用与影像舞台 |
| `--color-surface` | `#111315` | 主表面 |
| `--color-surface-raised` | `#181b1e` | 弹层和提升面 |
| `--color-text` | `#f5f4ef` | 暖白主文本 |
| `--color-text-muted` | `#999d9c` | 次要文本 |
| `--color-border` | `#292d30` | 分隔和轮廓 |
| `--color-accent` | `#d9ff43` | 选中、焦点、主操作 |
| `--color-success` | `#77e7ad` | 完成/在线 |
| `--color-warning` | `#ffc766` | 警示 |
| `--color-danger` | `#ff735f` | 高风险操作/错误 |
| `--color-focus` | `#d9ff43` | 焦点环 |

颜色不得是状态的唯一线索。错误、审查决定、在线状态都必须同时有文字或图标。文本对比达到
WCAG 2.1 AA，普通文本至少 4.5:1，大文本和非文本关键边界至少 3:1。

### 字体与密度

- 字体栈：`Inter, "SF Pro Display", "Helvetica Neue", "PingFang SC", "Microsoft YaHei", sans-serif`。
- 不用仿杂志衬线字模拟 Mac 或印刷界面。
- 数字、进度、容量使用 `font-variant-numeric: tabular-nums`。
- 8–10 px 只用于短标签/数据眉题；密集控件 11–13 px；正文 14 px；图库主标题 44–72 px。
- 全大写只用于极短英文状态标签，中文和操作文案保持正常字形。

### 间距、圆角、轮廓

- 间距标尺：`2, 4, 8, 12, 16, 24, 32, 48 px`。
- 主布局沟槽 12–16 px，控件内边距至少 8×12 px。
- 紧凑控件圆角 10–12 px，照片卡片 10–13 px，面板/对话框 16–20 px。
- 胶囊只用于状态和离散切换，不让每个容器都变成药丸。
- 阴影只用于悬浮选择条、查看器和卡片 hover；不得让点击目标发生位置动画。

## 图标

- 主图标统一使用 Lucide React，常用 16/18/20 px，`stroke-width` 保持 1.75–2。
- 纯图标按钮必须有可计算的 `aria-label`；不常用或高风险操作必须显示文字。
- 品牌、媒体、地图不得用 emoji 代替。

## 布局断点

| 宽度 | 形态 |
| --- | --- |
| `>= 1280` | 224 px 导航 + 照片主舞台；状态检视器默认收起，按需叠加 |
| `900–1279` | 保留文字导航，检视器作可叠加侧板，避免图标含义猜测 |
| `600–899` | 单列主画布，导航和检视器是 sheet，批处理工具固定于安全区上方 |
| `< 600` | 图标化顶栏、两列照片墙、折叠筛选；无水平滚动和安全区遮挡 |

规则不绑定具体设备，需同时验证 1440×960、1024×768 和 390×844。

## 图库与影像舞台

- 照片卡片在默认状态尽量少显示 chrome，名称与来源使用底部渐隐层。
- hover 可以改变边框、阴影和图片缩放，但卡片盒本身不能位移，保证点击稳定与性能门。
- 选择使用酸性黄绿轮廓和明确图标；收藏使用独立暖色，不只依赖颜色。
- 查看器使用近黑全屏舞台，详情作为内部侧栏；全局反馈必须渲染在 modal 顶层内，避免 inert。
- 真实图片比例和解码质量以 Host 为准；CSS 不裁剪原图详情视图。

## 交互和反馈

- 桌面鼠标密集控件可视高度不低于 32 px；触控命中区不小于 44×44 px。
- hover、pressed、selected、focus-visible、disabled、loading 和 destructive 必须可区分。
- 小范围成功用就地反馈；全局任务用可追踪 activity；错误不能只依赖短暂 toast。
- 高风险写操作显示目标数量、作用范围、可否撤销和 Host 返回的实际结果。
- 状态检视器默认关闭，不能长期挤占图库；连接状态在移动顶栏仍保留可见信号。

## 焦点、键盘和动效

- `:focus-visible` 使用 2 px 外环与 2–3 px offset。
- 主区域有 skip link；弹层焦点圈定，关闭后返回触发元素或合理后继。
- 图库支持方向键移动、Space 选择、Enter 查看、Escape 返回；快捷键不干扰输入框。
- 常规过渡 120–180 ms；虚拟网格点击目标不得用位移动画。
- `prefers-reduced-motion: reduce` 时取消非必要过渡、自动滚动和缩放；状态不依赖动画表达。

## 主题与高对比

- 设置契约保留 `system | light | dark`，只保存模式选择，不保存业务数据；当前品牌视觉以 Nocturne 为主。
- 近黑不是简单反相：照片卡片、主舞台、侧栏和提升面使用不同明度，并以暖白文字减少刺眼感。
- `forced-colors` 下使用系统色，恢复按钮/输入轮廓，不依赖背景图或阴影表达选中。
