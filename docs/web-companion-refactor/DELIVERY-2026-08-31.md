# Web Companion React 重构交付（2026-08-31）

## 交付结论

Web Companion 已从单体 HTML/CSS/JavaScript 迁移为 Vite + React 19 + strict TypeScript 应用，根入口
`/` 和 `/index.html` 默认跳转到 `/web-v2/gallery`。Swift Host 继续拥有认证、授权、API、媒体、
PhotoKit/GRDB 和高风险操作的最终权威；前端不复制业务数据库，也不把私有媒体或 API 响应写入
Service Worker Cache Storage。

旧版没有删除，冻结保留在 `/legacy/` 与 `/legacy/index.html`。保留原因是需要至少一个稳定发布
周期，以及项目所有者在真实发布环境完成 VoiceOver 听读和 MapLibre/Host 人工验收。访问旧版会从
旧版默认工作区开始；旧版不解析新版 URL，因此不声称无损跨实现上下文桥，也不传递 token、密码、
绝对路径、选择或表单草稿。

## 已完成能力

- 工程：Vite、React Router、TanStack Query/Virtual、Zod、strict TypeScript、ESLint、Prettier、
  Vitest、Playwright；生产资产带内容 hash，并由 Swift 审计 manifest 后固定交付。
- 会话：恢复、并发 401 单次 refresh、配对、账户登录、退出、断线重连、工作区通知与命令面板；
  Basic 凭据只在内存，浏览器存储检查不含测试配对码或密码。
- 图库：来源/相对文件夹树、搜索、筛选、排序、comfortable/compact、分页虚拟化、滚动锚点、
  单选/Shift/Meta/已载入全选/右键/框选、收藏、标签决定/撤销、检查器与路由化 viewer。
- viewer：前后切换、相邻预取、全屏入口、缩放/平移、快速切换取消、最大 6 个缩略图请求、URL
  去重/短复用/revoke；媒体继续使用 Host 的 GET/HEAD/Range 与会话边界。
- 工作区：图库/审查概览、审查队列、标签库、来源、存储、活动、设置、配对设备、世界地图、位置
  回填/地方标签、训练、嵌入准备、样本/全库/按标签建议、图库精简、相似聚类、清理计划与回收。
- 输入与反馈：鼠标、右键、拖框、触控尺寸、键盘网格/快捷键、焦点返回、History、dialog/确认、
  Host 权威成功/部分失败/冲突/撤销/重试提示；语义角色、状态和 live region 可供屏幕阅读器使用。
- 响应式与主题：1440×960、1024×768、390×844；system/light/dark、reduced-motion、
  forced-colors、200% 文字和页面缩放。
- PWA：公共外壳原子预缓存、离线恢复说明、旧 cache 清理和升级；明确禁止离线缓存私有照片、
  缩略图、预览、媒体、API、token 或元数据。

## 回滚与旧版退出

立即人工回退可直接访问 `/legacy/`。要恢复默认入口，在当前后续历史上创建一个可审计的本地回滚
提交：

```text
git revert 66284a2a
```

随后重新构建即可恢复切换前根入口和根 Service Worker；该操作不回滚数据库 migration，不删除或
改写用户数据。不要用 reset、checkout 或清理命令替代可审计 revert。

旧版删除必须另开阶段并满足：至少一个稳定发布周期；人工 VoiceOver 与真实发布环境
MapLibre/Host 验收；穷尽旧路由/selector/资源/SW/CSP 引用；把仍有价值的行为回归迁入新版；以独立
本地提交删除并重新执行所有适用门。当前交付明确选择“保留”，不把尚未发生的稳定周期写成完成。
