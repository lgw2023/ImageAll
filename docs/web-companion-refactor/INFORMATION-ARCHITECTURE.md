# 信息架构与路由

## 顶层架构

```text
Web Companion
├─ 图库
│  ├─ 全部照片
│  ├─ 收藏
│  ├─ 来源/文件夹范围
│  └─ 图库概览
├─ 审查
│  ├─ 总览
│  └─ 队列
├─ 工具
│  ├─ 世界地图
│  ├─ 训练
│  └─ 图库精简
└─ 管理
   ├─ 照片来源
   ├─ 存储与维护
   ├─ 标签库
   ├─ 活动与任务
   └─ 通用设置
```

会话恢复、配对、错误恢复和离线外壳是应用入口状态，不是主导航项。单张照片、批处理预览、筛选、
设置编辑和任务详情属于上下文层，不占用顶级入口。

## 规范路由

| 路由 | 语义 | 可共享 |
| --- | --- | --- |
| `/web-v2/gallery` | 图库默认视图 | 是，包含非敏感筛选/排序 |
| `/web-v2/gallery/favorites` | 收藏视图 | 是 |
| `/web-v2/gallery/overview` | 图库统计概览 | 是 |
| `/web-v2/assets/:assetId` | 单资产查看上下文 | 仅在当前 Host 会话中有意义 |
| `/web-v2/review` | 审查总览 | 是 |
| `/web-v2/review/queue` | 审查队列 | 是 |
| `/web-v2/map` | 世界地图 | 是 |
| `/web-v2/training` | 训练工作区 | 是 |
| `/web-v2/slimming` | 图库精简工作区 | 是 |
| `/web-v2/sources` | 来源管理 | 是 |
| `/web-v2/storage` | 存储与维护 | 是 |
| `/web-v2/tags` | 标签库 | 是 |
| `/web-v2/activity` | 长时任务和活动 | 是 |
| `/web-v2/settings` | 通用设置 | 是 |

URL query 只接受稳定、非敏感、可重现的视图参数：`source`、`folder`、`favorite`、`sort`、`direction`、
`view`和已定义的标签筛选。不将 token、密码、批量 payload、媒体 URL、自由文本备注或完整资产详情写入
URL、History 或本地存储。

## 全局壳层

- 顶栏：当前空间标题、连接状态、全局搜索入口、当前流程最多 1–2 个主操作。
- 侧边栏：以任务语义分组，不把所有按钮平铺到顶栏。
- 主画布：当前列表/网格/地图/工作流。
- 检视器：当前选中对象的详情、属性和上下文操作。
- 活动中心：长时任务、进度、失败原因和可执行后续。

## 响应式信息优先级

1. 照片/当前任务始终优先。
2. 选择数量、写操作范围和主操作在移动端不得被隐藏。
3. 筛选摘要以 chip/一行摘要存在，编辑放入 sheet。
4. 检视器在窄屏为独立路由或 sheet，并保留返回后的选择和滚动位置。
5. 辅助统计、低频设置和长说明可折叠，但不得吞掉错误或风险说明。
