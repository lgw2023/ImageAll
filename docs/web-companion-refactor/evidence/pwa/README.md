# PWA 与离线证据

`pwa.spec.ts` 在允许 Service Worker 的独立浏览器上下文中验证：manifest 字段、公共 shell
预缓存、离线入口、带查询参数的升级、旧 cache 删除，以及断网重载后不出现资产、缩略图、预览、
媒体或 API 数据。

升级回归发现并修复了两项真实问题：安装时部分写入会留下不完整 cache，以及带压缩传输头的缓存
响应在离线导航中不可复用。当前实现先完整抓取公共资源再原子写入，移除不可安全重放的传输头，
并以忽略查询和 `Vary` 的方式匹配公共入口。普通 E2E 默认禁用 Service Worker，防止 PWA 拦截掩盖
合成 Host 路由；只有本专项显式启用。

证据只证明公共外壳可恢复，不声明离线可浏览私有照片；后者按安全契约明确禁止。
