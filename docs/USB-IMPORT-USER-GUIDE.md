# 从 iPhone 导入到 Mac ImageAll：当前操作流程

更新：2026-10-27。以日常 ImageAll 界面为准。本次6张新增照片已完成真实USB导入，结果记录在文末。

## 平时只需完成这条路径

**插线并打开双端（已配对自动连接） → 手机点“导入新增内容” → 确认并发送 → 出现“可以拔线” → Mac 自动完成 → 在原来源浏览。**

### 1. 打开双端

- Mac：按平时方式在 Xcode 运行 ImageAll。日常连接无需打开设置。
- 手机：解锁实体 iPhone，打开日常「ImageAll」，保持前台。不要打开独立的「USB 验收」App。
- 首次设置或更改保存位置时，才打开「ImageAll → 设置… → 设备与导入」（⌘,）。继续追加沿用已有目录和来源。
- 首次使用才需要系统信任与照片权限；相簿名称及层级需要完整照片权限。手机原件保留，本流程不启用 iCloud 原件下载。

### 2. 连接 USB

1. 插上 USB，打开双端 ImageAll；手机保持前台，Mac 的“允许连接”保持开启。
2. 已配对的同一 Mac 会自动连接，不需要进入设置或在两边点连接按钮。
3. 首次连接或 Mac 身份变化时，手机会显示身份确认；核对后确认。系统首次“信任此电脑”和照片权限仍按系统提示操作。
4. 手机显示“USB 有线 · 已连接”后，从手机开始导入；自动连接不会自动发送照片。

手动暂停后，可点“恢复自动连接”（手机）或“连接 iPhone”（Mac）恢复。Mac 侧手动断开也可通过拔插恢复。明确选择过网络连接的手机保持原偏好，需要手动切回 USB 一次。多台USB手机同时在线时在Mac选择目标。手机进后台会暂停通道，回到前台自动连接；任务续传仍由用户主动继续。拔线不会自动改走网络。

### 3. 只选择上次之后新增的内容

若页面仍显示旧批次已选数量，这是保留的上次选择，不代表需要再次发送。

1. 在手机「此 iPhone」首页点蓝色「导入新增内容」。也可从「待分享」首页直接进入。
2. 点「预览已授权范围」，核对照片、视频数量。
3. 点「确认将这 N 项加入待分享」。确认后直接进入待分享，核对「已选 N 项」，连接目标 Mac 并开始导入。
4. 若显示「暂无新增内容」，返回即可；旧任务和选择保持。

新增范围按既有任务成员排除，不按拍摄日期筛选，需要完整照片权限。首次使用的首页按钮是「导入到 Mac」；未完成任务也从这里继续原任务。更多操作中的「再次导入当前选择…」会沿用已有选择，不用于自动选择新照片。

### 4. 从手机开始导入

确认目标 Mac、已选数量及「包含相簿目录（含空相簿）」选项，点底部「导入所选照片与信息」。照片原件、相簿结构及本批整理信息一起发送，不需要先手动「同步目录」。

传输期间让手机 ImageAll 保持前台，保持线缆和目标磁盘连接。中途退出或断线后，恢复同一连接、继续同一任务；不重新选择旧批次。

### 5. 何时可以拔线

以手机明确出现 **「传输完成 · 可以拔线」** 为准。此时 Mac 已持久接收并接管任务，之后的核验、入库、发布及 Mac 暂存收尾不需要手机在线。

拔线后保持 Mac ImageAll 运行、目标磁盘连接。不能把「目录已收到」、资源进度到末尾或旧任务的「状态待刷新」当成新任务交接完成。

### 6. 到 Mac 查看结果

Mac 在「设置 → 设备与导入」的同一张导入卡显示本批状态；完成后点「查看照片」直接打开原来源。也可从主窗口左侧「来源 → iPhone · 已导入 Mac」进入。

新流程不需要再点一次「导入照片与信息」。历史批次和维护工具默认收起；旧版封存批次的手动入库在「接收选项与离线导入」中。连接新设备、已配对设备、公网访问、网页访问白名单及本机调试直接显示在同页，与“从 iPhone 导入”并列；诊断和旧版分享目录仍可按需展开。
