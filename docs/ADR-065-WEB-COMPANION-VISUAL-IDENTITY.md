# ADR-065：Web Companion 采用独立的 Prism 视觉身份

- 状态：Accepted（2026-09-01 项目所有者反馈后修订）
- 日期：2026-09-01
- 范围：`WebCompanionApp` 与打包到 Mac App 的 `WebCompanionV2` 静态资源

## 背景

Web Companion 的功能对齐目标是：关键任务、状态语义、Mac Host 权威、安全边界与跨设备连续性
保持一致。它不要求复制 Mac App 的窗口、侧栏、面板密度或系统控件外观。

上一版 React 界面虽然完成了功能迁移，但先后把“三列信息关系”误解成桌面 App 的视觉复刻，又把
“独立视觉”收窄成过度克制的档案馆排版。两者都更像管理后台：状态卡与工具面板争抢注意力，照片没有
成为主角。项目所有者明确澄清：功能与 Mac App 对齐不代表外观也要对齐；Web 应参考业内成熟产品，
做成更现代、更有表现力的独立前端。

## 参考研究

本次只提取成熟产品的交互规律，不复制任何单一产品的品牌或界面：

- [Immich](https://immich.app/)：照片和视频内容优先、管理能力围绕媒体展开；
- [Eagle](https://en.eagle.cool/)：面向大规模素材的快速浏览、多维筛选、悬停预览和键盘预览；
- [Air](https://air.inc/)：创意资产以高质量缩略图、轻量导航与任务上下文组织；
- [Cosmos](https://play.google.com/store/apps/details?id=so.cosmos.www)：以视觉发现、收藏和协作为核心，
  弱化文件管理负担；
- [Linear](https://linear.app/)：用精确层级、低噪声导航和即时状态反馈承载复杂工作流。

## 决策

Web Companion 采用 **ImageAll Prism** 作为独立视觉方向：

1. 以深色沉浸画布承载照片；紫罗兰与冷青只作为环境光、选中态和主要动作，不覆盖媒体内容；
2. 使用本机无衬线字体与紧凑数字排版，不请求外部字体；标题可以大胆，但工具文字保持克制；
3. 桌面导航、顶栏和可选检视器采用低对比半透明框架，让工作区成为唯一视觉主角；
4. 图库采用大缩略图、弱边框、下缘元数据和悬停抬升；完整比例仍在灯箱中以 `contain` 呈现；
5. 复杂 Host 能力不再堆成左侧设置栏，而以横向任务工作台、双轨状态卡和内容入口分层表达；
6. 移动端折叠为内容优先双列影像流，任务工作台转为单列，同时保留筛选、分析和框选入口；
7. 渐变、玻璃模糊和柔和光效可用于建立空间层级，但不得降低文本对比、遮盖照片或引入循环动画。

图库、概览、审核、地图、训练、瘦身、来源、存储、标签、活动、设置和认证入口共享同一套颜色、字体、
间距、按钮与状态语言，而不是只给图库换皮。

## 不变契约

- Mac Host 继续是列表、修改、任务和设置的唯一权威，网页不伪造成功；
- 路由、URL 筛选、选择语义、快捷键、右键菜单、撤销、灯箱返回上下文与分页契约不变；
- 10k 图库继续使用虚拟化；PWA 仍只缓存公开壳层，不缓存私有媒体或会话数据；
- 深色模式、高对比模式、放大文字、减少动态效果和 390px 触控布局继续受自动化约束；
- 自动化只使用合成 Host 与合成媒体，不读取、遍历或写入受保护真实图库。

## 取舍

- 系统无衬线字体在不同平台字形会略有差异，但换取离线可用和零外部跟踪；
- 接触印样采用 4:3 裁切以提高浏览密度，精确构图判断必须进入无裁切灯箱；
- 半透明与环境光比纯色后台更依赖渲染能力，因此强制颜色、减少动态效果和无 `backdrop-filter`
  环境必须继续由基础颜色与边框兜底。

## 验证

- Playwright：108 项中 104 项通过、4 项按浏览器项目配置跳过、0 失败；
- 10k 合成图库：首卡可交互 993 ms，DOM 713，卡片 35，选择反馈 p95 16.9 ms，灯箱 p95
  118.3 ms，长任务 0，滚动锚点偏差 0 px；
- `format:check`、lint、typecheck、31 个 Vitest 单元/契约测试和 macOS `build-for-testing` 通过；
- 当前桌面/移动截图位于 `docs/web-companion-refactor/evidence/gallery/` 与
  `docs/web-companion-refactor/evidence/curation/`。
